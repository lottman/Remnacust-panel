# Версии и совместимость

| Компонент | Remnacust | Официальная основа |
| --- | --- | --- |
| Backend и frontend | 1.1.7.41 | Remnawave 3.4.5 |
| Агент ноды | 1.1.15-remnacust | Remnawave Node 3.4.2 |
| Ядро | 1.1.9 | Официальный тег Xray-core v26.10.10 (prerelease) |
| Страница подписки | 1.1.7.41 | Subscription Page 8.0.0 |

Панель учитывает метку Remnacust при выборе функций агента. Геопроверка поддерживается с Remnacust Node 1.1.1 и Remnawave Node 3.3.0. Полная таблица старых нод: [NODE-COMPATIBILITY.md](NODE-COMPATIBILITY.md).

Квоты отдельных хостов и тегов, ограничение скорости и немедленный отзыв соединений устройства требуют нашего агента и ядра. Для обычных профилей можно сохранить стандартную ноду, если её Xray поддерживает используемые протоколы и транспорты.

Панель включает изменения Remnawave 3.4.5: gRPC multiMode, точный фильтр ID, настройку SNI при подключении к ноде и плагин postStart. Нода обновлена до основы 3.4.2; ядро включает исправления официальной ветки после 26.9.30. Подробности: [REMNAWAVE-UPDATES.md](REMNAWAVE-UPDATES.md).

Исходники ядра и редактора находятся в [Remnacust-core](https://github.com/lottman/Remnacust-core). Начиная с Core 1.1.6 используется строго официальный опубликованный тег Xray v26.10.10 (`701af60772cda123492f86e383e1fdba066614a9`, prerelease), без дополнительных коммитов из main; происхождение записано в его `xray/REMNACUST-UPSTREAM.json`. Предыдущий Core 1.1.5 использует основу 26.9.30. Редактор должен собираться из тех же строителей конфигурации, что и ядро; В текущем опубликованном комплекте 1.2.72 используются Core/WASM 1.1.9 и Node 1.1.15. Архив ядра, валидатор и схемы проверяются при подготовке выпуска.

[Страница подписки](../subscription-page/README.md) собирается и обновляется отдельно. Её токен API нужен для обращения к панели; он не используется для скачивания публичного установщика. Сохраните существующий токен и настройки оформления при обновлении.

Локальные резервы и восстановление неподтверждённого расхода: [QUOTA-RECOVERY.md](QUOTA-RECOVERY.md). Недоступная панель не выдаёт новый резерв; уже выданный остаток используется локально. Области действия квот и скорости: [HOST-LIMITS.md](HOST-LIMITS.md). Старые промежуточные статусы в аудитах не являются описанием текущего выпуска.
