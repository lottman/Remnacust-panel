# Домены подписок и оформление — проверка 1.1.7.77 / 1.2.113

Проверка относится к синхронизации основного домена и общим заголовкам интерфейса. Это не аудит всех функций панели и не проверка рабочей инфраструктуры оператора.

- Настоящая PostgreSQL в отдельной тестовой БД: импорт `.env`, HTTPS URL и путь, запись основного адреса, сохранение UUID и названия, устаревшее окружение другого процесса, параллельное чтение, конфликт CDN и откат БД при отказе службы. БД удалена после проверки.
- Настоящий Unix-сокет: HMAC, отказ с неверным токеном, ограничение тела, запрещённые поля, проверка ревизии и отсутствие секретов в ответе. Доступ через произвольный HTTP endpoint не добавлялся.
- Отдельный сквозной стенд соединяет настоящую PostgreSQL, TypeScript-сервисы панели, HMAC Unix-сокет, Python-службу и файлы `.env`/Compose. Смена основного домена записалась на сервер, ручная правка файла вернулась в реестр; остальные секреты сохранились. Временная БД и процесс службы удалены.
- Файловые проверки: сохраняются остальные переменные и чужие сервисы; конфликт ревизий не затирает ручную правку. Символические/жёсткие ссылки и FIFO отклоняются, активный установщик не прерывается. Ошибка посреди записи восстанавливает только файлы этой операции. Копии находятся внутри `backups`, повтор без изменений не увеличивает их количество.
- Chrome с реальными компонентами и тестовыми ответами API: порядок вкладок, доступность доменов при ошибке службы страниц, светлая/тёмная тема, смена акцента и ширина 390 px. Цвета общих заголовков совпадают; горизонтального переполнения страницы нет. Таблица сохраняет собственную прокрутку. Рабочая панель во время проверки была недоступна.
- Сообщения и документация проверяются на RU/EN/FA/ZH; OpenAPI пересоздан из текущих контрактов.

Границы: синхронизация требует локальной службы и зарегистрированного Compose в JSON-представлении. CDN не заменяет основной адрес `.env`. Конфликт с существующим CDN не исправляется сменой его типа. DNS, сертификаты и внешний CDN не изменяются. Доступность панели и нод не зависит от этой служебной синхронизации.

БД и файлы не составляют общую транзакцию: при обычном отказе БД после подтверждённой записи предусмотрен обратный CAS-запрос. Если процесс/служба аварийно завершается между этапами, следующая сверка использует текущее значение `.env`; интерфейс при неподтверждённой записи не показывает успех. Параллельная правка защищена ревизией, а исходные файлы остаются в приватной копии.
