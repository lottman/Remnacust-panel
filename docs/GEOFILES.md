# Geofiles и клиентские правила

Редакторы Xray JSON, sing-box, Mihomo, Clash и Stash имеют вкладку **Геофайлы**. Она использует тот же черновик, что код, автовыбор и история. Загрузка совместимого файла добавляет его в текущий черновик; рабочий шаблон изменяется только после сохранения.

## Как настроить

1. Откройте шаблон → Геофайлы. Нажмите «Нажмите, чтобы загрузить» для выбора файла с компьютера или укажите прямую HTTPS-ссылку, название и формат содержимого. В блоке «Готовые наборы» можно импортировать опубликованный GeoIP/GeoSite из каталога.
2. Совместимый загруженный файл сразу прикрепляется к текущему черновику. Уже готовый файл выберите в библиотеке и нажмите «Добавить в шаблон». Один файл можно использовать в нескольких шаблонах; идентичный контент того же формата повторно не сохраняется.
3. Для DAT выберите категории, например `ru`, `private`, `google`; названия берутся из самого файла. Можно ввести категорию вручную, в том числе `category@attribute` для GeoSite.
4. Явно выберите действие: DIRECT, REJECT или существующая группа автовыбора. С пустым действием текст можно сохранить как серверный черновик с предупреждением; в подписках остаётся последняя рабочая версия.
5. Проверьте отличия и сохраните. Корректный шаблон применяется, клиент получает изменения при обновлении полной конфигурации подписки. Черновик с ошибками сохраняется на сервере и в истории, но не заменяет рабочую конфигурацию.

Уже указанные в коде `geodata.assets`, `geox-url`, `rule-providers` и `route.rule_set` не заменяются. Их URL отображаются для повторного импорта в библиотеку. Самостоятельно существующий удалённый файл на компьютере клиента панель обнаружить не может.

## Размер встроенной конфигурации

Способ доставки выбирается автоматически для итоговой конфигурации. Сначала выбранные категории преобразуются в правила; совпадающие условия одного типа включаются один раз. DIRECT, REJECT, балансеры и порядок маршрутов сохраняются. Списки INCY без запятых могут использовать поддерживаемую Xray строковую форму без потери условий; regexp с запятыми остаётся массивом.

Размер и сложность проверяются **по одному профилю хоста**, без суммирования остальных хостов. Бюджет панели для INCY — 900 000 байт после форматирования с четырьмя пробелами; это запас совместимости, а не опубликованный точный предел приложения. Общий ответ ограничен отдельно 16 MiB. Если один профиль слишком велик или превышен предел разворачивания правил, поддерживаемым Happ/INCY выдаются подписанные DAT. Неподдерживаемый формат или конфликт с ручными геоданными возвращает ошибку без удаления правил.

Встроенное разворачивание одного DAT ограничено 50 000 условиями и 2 MiB текста. Для удалённой выдачи категории проверяются без разворачивания всех условий. Прежнее поле `downloadToClient` принимается для совместимости, но больше не выбирает доставку.

Существующие правила сохраняют порядок. Новые правила вставляются перед общим маршрутом, включая Xray TCP/UDP в любом порядке и массив TCP/UDP в sing-box. Добавление геофайла не заменяет собственную маршрутизацию шаблона.

## Готовые наборы

Это единый каталог всех шаблонов: загруженные с компьютера и по URL файлы находятся здесь рядом с источниками V2Fly/MetaCubeX. Несовместимый формат остаётся видимым, но добавить его в текущий шаблон нельзя. Импортированный готовый набор показывается одной записью. Удаление из каталога удаляет файл для всех шаблонов; действующая сохранённая привязка блокирует удаление с ответом 409. Сначала уберите её и сохраните шаблон. Несохранённая привязка текущего редактора удаляется вместе с файлом, остальные изменения черновика сохраняются.

Каталог содержит опубликованные DAT-наборы [V2Fly GeoIP](https://github.com/v2fly/geoip), [V2Fly GeoSite](https://github.com/v2fly/domain-list-community) и [MetaCubeX](https://github.com/MetaCubeX/meta-rules-dat): полные базы стран/доменов, отдельные частные IP и GeoSite Lite с сокращённым набором сервисов. Ссылка на источник видна перед импортом. Файл скачивается только после нажатия кнопки, через тот же защищённый импорт HTTPS с проверкой содержимого и ограничением размера. Каталог не обходит ограничения безопасности.

Импорт выбирает файл в общей библиотеке. Он не включает правила и не меняет черновик: добавьте файл в шаблон, выберите категории и действие, затем сохраните. Совпадающее содержимое того же формата повторно не хранится. Автообновление источника по умолчанию выключено; включите его и задайте серверный интервал в библиотеке либо повторите импорт вручную. Если источник недоступен, загрузите файл с компьютера или повторите позже.

## Форматы и доставка

В карточке остаются категории, действие и интервал клиента; подробности совместимости раскрываются отдельно. Для небольших встроенных правил отдельная загрузка не требуется. Обычные URI/Base64-ссылки не передают произвольные геофайлы и полную маршрутизацию.

| Данные / клиент | Доставка |
| --- | --- |
| GeoIP / GeoSite, Happ или INCY | Встроенные правила; при превышении бюджета — объединённые DAT и профиль первоначальной загрузки |
| GeoIP / GeoSite, другие Xray-клиенты | Встроенные правила; неподдерживаемый большой профиль возвращает ошибку |
| GeoIP / GeoSite, sing-box / Mihomo / Clash / Stash | Небольшие правила встроены; большие преобразуются в поддерживаемый удалённый набор |
| sing-box JSON | Небольшой набор встроен, большой — remote rule set |
| sing-box SRS | Бинарный набор всегда загружается |
| Нативные наборы Mihomo / Stash | Небольшой набор встроен при поддержке формата; большой — HTTP provider |
| Нативные наборы старого Clash | HTTP provider для совместимости |

Автообновление сервера может публиковать новое содержимое по стабильной подписанной ссылке. Неизменяемый URL с SHA-256 сохраняет исходное содержимое. Проверки новых данных на сервере и клиентское расписание независимы.

## Защита загрузки и хранения

- Управление доступно только администратору через текущую сессию панели. API-токен и роль наблюдателя не дают права загрузки или удаления.
- Импорт только по HTTPS на порту 443. Запрещены встроенные учётные данные, локальные, приватные, служебные и зарезервированные IPv4/IPv6. Проверяются все DNS-ответы и каждый из максимум трёх переходов; подключение закрепляется за проверенным адресом. Cookie, токены панели и настройки прокси не пересылаются.
- Общий тайм-аут импорта 30 секунд, тайм-аут сокета 10 секунд. Не принимается сжатый HTTP-ответ. Размер ограничен и при потоковой передаче без Content-Length.
- До 32 файлов по 64 MiB; текстовые данные до 8 MiB. Не более двух одновременных импортов на API-процесс. Ограничены глубина JSON, YAML aliases/merge, число protobuf-полей и распаковка SRS. HTML, архивы, обрезанные и несовместимые данные отвергаются.
- Проверка одинакового содержимого и публикация записи выполняются под общей блокировкой PostgreSQL между API-процессами. Одновременный импорт одного формата с тем же SHA-256 возвращает один идентификатор; скачивание и проверка файла происходят до блокировки.
- Имена пользователей не становятся путями: фиксированные слоты, случайные идентификаторы, SHA-256 и серверное расширение. Ссылки и символьные ссылки не используются для произвольного чтения. Файлы выдаются как attachment/octet-stream с `nosniff` и CSP sandbox.
- Лимит встроенных правил: 50 000 на набор, 100 000 суммарно; конфигурация до 8 MiB, весь Xray JSON ответ до 16 MiB. Превышение лимита разворачивания переключает поддерживаемую выдачу на DAT; при невозможности безопасной выдачи возвращается ошибка, а не обрезанный профиль.

URL файлов общедоступны для клиентов, знающих ссылку. Храните только публичные наборы правил, без секретов и персональных списков. Ссылка не является авторизацией пользователя подписки. Текущий шаблон защищает используемый файл от удаления; старые версии истории после удаления файла могут потребовать повторной загрузки и привязки.

## Сохранность и перенос

Библиотека хранится в `backups/geofiles` внутри существующего постоянного тома панели (`XERA_BACKUPS_DIR`, обычно `/opt/app/backups`). Обновление контейнера сохраняет её. **Резервная копия только БД не содержит бинарные файлы:** для полного переноса копируйте также каталог `geofiles` с его метаданными и данными. Не изменяйте файлы вручную.

## Если загрузка не прошла

Для импорта нужна прямая публичная HTTPS-ссылка без авторизации и HTML-страницы. Если источник не успевает отдать файл за 30 секунд, скачайте его самостоятельно и загрузите с ПК. При HTTP 413 проверьте ограничение тела запроса своего внешнего reverse proxy: оно должно разрешать выбранный размер файла. Встроенные ограничения панели при этом сохраняются.


## Доставка и два расписания

Ручного переключателя загрузки больше нет. У новой привязки задаются файл, категории, действие и `clientRefreshIntervalSeconds`. Действие не зависит от способа доставки: DIRECT, REJECT или существующая группа/балансер. Только для старой записи с `downloadToClient: false` и отсутствующим `target` сохраняется совместимое начальное действие DIRECT. Пустое или неверное действие не применяется молча.

- **Клиентский интервал** действует при удалённой доставке: от 5 минут до 30 дней. Приложение само определяет фактическое расписание и повторы после сетевой ошибки. При встроенной выдаче URL геофайлов очищаются и периодическая загрузка отключается.
- **Серверное автообновление** настраивается в библиотеке файла: HTTPS-источник, включение и интервал от 15 минут до 30 дней. Новое содержимое проверяется до публикации. При ошибке остаётся рабочая версия; повторная попытка учитывает кулдаун.

Загрузка и настройки общей библиотеки сохраняются сразу. Изменение привязки в шаблоне сначала меняет его черновик; примените его кнопкой сохранения и обновите подписку в приложении.

## Первоначальная загрузка DAT в Happ и INCY

Нужна полная JSON-подписка: включите «Отдавать JSON на базовом пути подписки» либо используйте ссылку с окончанием `/json`. Панель передаёт поддерживаемый приложением заголовок `routing` с профилем и ссылками GeoIP/GeoSite. Название берётся из `profile-title` подписки, включая переопределения сквада, иначе используется домен подписки. Стабильный короткий суффикс различает одинаковые названия.

Формат V2Fly DAT сам по себе не мешает загрузке. Несколько файлов одного вида объединяются в DAT с изолированными именами категорий. Новые ссылки используют namespace 2; старые подписанные ссылки namespace 1 поддерживаются с отдельным кешем. Действия и балансеры остаются в полном JSON. Заголовок до 3000 байт может не дублировать все категории — из самой конфигурации правила не удаляются.

Ручной заголовок routing и существующие геоданные не перезаписываются. Если безопасная удалённая выдача невозможна, возвращается ошибка, а не частично рабочая подписка. При встроенной выдаче профиль очищает старые ссылки и расписание. Старый локальный профиль с названием Remnacust приложение может сохранить отдельной записью: сервер не может переименовать его сам.

При обновлении панели обновляйте также отдельно установленную страницу подписки. Изменения применяются после обновления подписки в приложении; анимация скачивания не является подтверждением корректности правил.

## INCY: файлы, расписание и контрольные суммы

INCY получает стабильные DAT-ссылки без query-параметров; подписанная выборка находится в пути. Добавление `.sha256` возвращает SHA-256 того же объединённого файла. `LastUpdated` обновляет профиль, а `routing-geo-update-interval` задаётся в часах. Неизменившийся файл можно проверить без повторной загрузки.

Предел JSON 16 MiB не относится к потоку DAT: его отдельный предел — 64 MiB. Страница подписки должна передавать файл полностью; обрезанный DAT может вызвать EOF или отсутствие категории. Сравните полный размер и SHA-256, обновите страницу подписки и затем подписку в приложении. Содержимое файла на сервере и устаревший локальный DAT на телефоне могут различаться.

Точный численный предел INCY iOS 2.6.2 не опубликован в доступной официальной документации. Число в `The configuration is too large` — размер отвергнутой конфигурации, а не допустимый максимум. Проверка ядром настольной версии не заменяет проверку на физическом iPhone. Панель не запускает туннель клиента.

## Пул и получатели шаблона

Состав пула задаёт серверы, между которыми выбирает клиент. Назначение в той же карточке задаёт хосты подписки, использующие конкретный автовыбор, и привязано к имени балансера. При переименовании связь сохраняется. Выбор хостов и тегов взаимоисключающий. Старое неоднозначное назначение требует явного выбора автовыбора.

Предварительный счётчик показывает уникальные подходящие хосты до проверки доступа пользователя и случайной выборки. Отключённые хосты и исключения XRAY_JSON учитываются при выдаче и в интерфейсе. Для старого пула с именами хостов вместо tagPrefix направляйте правила на балансер: неиспользуемый префикс не предлагается как цель.

## Приоритет серверов (1.1.7.52)

Стратегия «По приоритету: первый доступный» выбирает первый работающий сервер. Для точного порядка выберите Хосты и Все выбранные хосты, затем переставьте их стрелками. Префиксы нескольких пулов также можно упорядочить в балансере. Теги и regex используют порядок общего списка хостов; случайные режимы сначала выбирают подмножество. Переключение и возврат на основной происходят после проверок доступности и затрагивают новые соединения; открытые соединения не переносятся. Xray JSON преобразуется при выдаче в стандартные leastPing-балансеры с одним кандидатом и цепочку Loopback. До первой успешной проверки и при отказе всех серверов соединение блокируется. Явный fallbackTag используется последним. При выборе приоритета GUI убирает автоматически заданный резерв на тот же пул; собственный резерв сохраняет. Параметры проверок сохраняются. Предел — 128 кандидатов на балансер и 256 на конфигурацию. Routing script и конфликтующие общие селекторы других балансеров несовместимы. В Mihomo/Clash/Stash используется native fallback с порядком proxies: явные участники из кода идут до пула. sing-box не поддерживает автоматический строгий приоритет в конфигурации; его selector ручной, URLTest выбирает по задержке. Нужна полная JSON/YAML-подписка.

Официальные механизмы: [Xray Loopback](https://xtls.github.io/en/config/outbounds/loopback.html), [Xray routing](https://xtls.github.io/en/config/routing.html), [Mihomo fallback](https://wiki.metacubex.one/en/config/proxy-groups/fallback/), [sing-box selector](https://sing-box.sagernet.org/configuration/outbound/selector/).
