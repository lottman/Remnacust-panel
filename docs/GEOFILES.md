# Geofiles и клиентские правила

Редакторы Xray JSON, sing-box, Mihomo, Clash и Stash имеют вкладку **Геофайлы**. Она использует тот же черновик, что код, автовыбор и история. Добавление файла в библиотеку не меняет шаблон само по себе.

## Как настроить

1. Откройте шаблон → Геофайлы. Нажмите «Нажмите, чтобы загрузить» для выбора файла с компьютера или укажите прямую HTTPS-ссылку, название и формат содержимого. В блоке «Готовые наборы» можно импортировать опубликованный GeoIP/GeoSite из каталога.
2. После загрузки выберите файл в библиотеке и нажмите «Добавить в шаблон». Один файл можно использовать в нескольких шаблонах; идентичный контент того же формата повторно не сохраняется.
3. Для DAT выберите категории, например `ru`, `private`, `google`; названия берутся из самого файла. Можно ввести категорию вручную, в том числе `category@attribute` для GeoSite.
4. Явно выберите действие: DIRECT, REJECT или существующая группа автовыбора. С пустым действием текст можно сохранить как серверный черновик с предупреждением; в подписках остаётся последняя рабочая версия.
5. Проверьте отличия и сохраните. Корректный шаблон применяется, клиент получает изменения при обновлении полной конфигурации подписки. Черновик с ошибками сохраняется на сервере и в истории, но не заменяет рабочую конфигурацию.

Уже указанные в коде `geodata.assets`, `geox-url`, `rule-providers` и `route.rule_set` не заменяются. Их URL отображаются для повторного импорта в библиотеку. Самостоятельно существующий удалённый файл на компьютере клиента панель обнаружить не может.

## Готовые наборы

Каталог содержит опубликованные DAT-наборы [V2Fly GeoIP](https://github.com/v2fly/geoip), [V2Fly GeoSite](https://github.com/v2fly/domain-list-community) и [MetaCubeX](https://github.com/MetaCubeX/meta-rules-dat): полные базы стран/доменов, отдельные частные IP и GeoSite Lite с сокращённым набором сервисов. Ссылка на источник видна перед импортом. Файл скачивается только после нажатия кнопки, через тот же защищённый импорт HTTPS с проверкой содержимого и ограничением размера. Каталог не обходит ограничения безопасности.

Импорт выбирает файл в общей библиотеке. Он не включает правила и не меняет черновик: добавьте файл в шаблон, выберите категории и действие, затем сохраните. Совпадающее содержимое того же формата повторно не хранится. Наборы не обновляются в фоне: повторите импорт для получения новой опубликованной версии. Если источник недоступен, загрузите файл с компьютера или повторите позже.

## Форматы и доставка

Отсутствие скачивания DAT в приложении само по себе не означает ошибку: выбранные категории уже находятся внутри выданной конфигурации. Панель не может заставить произвольное приложение загружать файлы через неизвестные ему поля JSON. Обычная ссылка VLESS и подписка из таких ссылок не содержат маршрутизацию, балансеры и geofiles; для них нужен импорт полного поддерживаемого JSON/YAML.

У прикреплённого файла интерфейс показывает способ доставки. Для встроенных правил отдельного сетевого запроса не будет. Для нативного удалённого набора показан публичный URL, который получит клиент; sing-box скачивает его как `remote rule_set`, а Mihomo/Clash/Stash — как HTTP `rule-providers`. Обновление неизменяемого URL не подменяет содержимое файла: новую версию набора нужно импортировать, прикрепить и получить при обновлении подписки.

| Данные | Xray JSON | sing-box | Mihomo | Clash / Stash |
|---|---|---|---|---|
| GeoIP / GeoSite DAT | Выбранные категории → встроенные правила | Выбранные категории → встроенные правила | Выбранные категории → встроенные правила | Выбранные категории → встроенные правила, кроме регулярных выражений GeoSite |
| sing-box JSON / SRS | — | Нативный удалённый `route.rule_set`, URL панели, обновление раз в сутки | — | — |
| YAML `payload`, domain / ipcidr / classical | — | — | Нативный HTTP `rule-providers` | Нативный HTTP `rule-providers` |
| Текст domain / ipcidr | — | — | HTTP `rule-providers` с `format: text` | — |

DAT компилируется на сервере в правила клиента. Поэтому можно выбрать несколько DAT без конфликта единственных клиентских `geoip.dat`/`geosite.dat`; клиенту не требуется предварительно создавать файлы для обновляющего механизма Xray. Загруженный DAT не обновляется сам из исходного URL: повторный импорт создаёт новую неизменяемую запись, если содержимое изменилось. Перепривяжите шаблон к новой записи. Прежние подписки и сохранённые версии не меняются задним числом.

Новые правила сохраняют порядок существующих ограничений и вставляются перед общим правилом. Явно пустой пул не переключает трафик в DIRECT. Смена имени группы обновляет привязки geofiles; при её удалении требуется заново выбрать действие. Сырые URI/Base64 не умеют передавать произвольные нативные группы и файлы всем приложениям; их формат не расширяется вымышленными параметрами. Happ Routing остаётся отдельным клиентским механизмом.

Для SRS версий 1–4 проверяются контейнер, ограниченная распаковка и вся структура записей: типы правил, вложенность, строки, доменные деревья, диапазоны IP и префиксы. Неизвестные типы, обрезанные записи и лишние данные отвергаются. Это не полный семантический анализ всех правил клиентом. Поддержка конкретных полей JSON/SRS зависит от версии sing-box. Генератор ориентирован на совместимость с sing-box 1.13.x. Приложение должно поддерживать соответствующий формат; тесты генераторов не заменяют испытание каждого приложения на реальном устройстве.

В обычном Xray JSON-профиле ограничение хоста DENY ставится перед правилами шаблона и geofiles, сохраняя остальные правила, балансеры и стратегию разрешения доменов. ALLOW_ONLY остаётся строгим переопределением: разрешённые домены идут в proxy, остальные блокируются; ручные маршруты не могут обойти этот запрет.

## Защита загрузки и хранения

- Управление доступно только администратору через текущую сессию панели. API-токен и роль наблюдателя не дают права загрузки или удаления.
- Импорт только по HTTPS на порту 443. Запрещены встроенные учётные данные, локальные, приватные, служебные и зарезервированные IPv4/IPv6. Проверяются все DNS-ответы и каждый из максимум трёх переходов; подключение закрепляется за проверенным адресом. Cookie, токены панели и настройки прокси не пересылаются.
- Общий тайм-аут импорта 30 секунд, тайм-аут сокета 10 секунд. Не принимается сжатый HTTP-ответ. Размер ограничен и при потоковой передаче без Content-Length.
- До 32 файлов по 64 MiB; текстовые данные до 8 MiB. Не более двух одновременных импортов на API-процесс. Ограничены глубина JSON, YAML aliases/merge, число protobuf-полей и распаковка SRS. HTML, архивы, обрезанные и несовместимые данные отвергаются.
- Проверка одинакового содержимого и публикация записи выполняются под общей блокировкой PostgreSQL между API-процессами. Одновременный импорт одного формата с тем же SHA-256 возвращает один идентификатор; скачивание и проверка файла происходят до блокировки.
- Имена пользователей не становятся путями: фиксированные слоты, случайные идентификаторы, SHA-256 и серверное расширение. Ссылки и символьные ссылки не используются для произвольного чтения. Файлы выдаются как attachment/octet-stream с `nosniff` и CSP sandbox.
- Лимит встроенных правил: 50 000 на набор, 100 000 суммарно; конфигурация до 8 MiB, весь Xray JSON ответ до 16 MiB. Превышение возвращает ошибку, а не обрезанный профиль.

URL файлов общедоступны для клиентов, знающих ссылку. Храните только публичные наборы правил, без секретов и персональных списков. Ссылка не является авторизацией пользователя подписки. Текущий шаблон защищает используемый файл от удаления; старые версии истории после удаления файла могут потребовать повторной загрузки и привязки.

## Сохранность и перенос

Библиотека хранится в `backups/geofiles` внутри существующего постоянного тома панели (`XERA_BACKUPS_DIR`, обычно `/opt/app/backups`). Обновление контейнера сохраняет её. **Резервная копия только БД не содержит бинарные файлы:** для полного переноса копируйте также каталог `geofiles` с его метаданными и данными. Не изменяйте файлы вручную.

## Если загрузка не прошла

Для импорта нужна прямая публичная HTTPS-ссылка без авторизации и HTML-страницы. Если источник не успевает отдать файл за 30 секунд, скачайте его самостоятельно и загрузите с ПК. При HTTP 413 проверьте ограничение тела запроса своего внешнего reverse proxy: оно должно разрешать выбранный размер файла. Встроенные ограничения панели при этом сохраняются.


## Доставка и два расписания (1.1.7.49)

В каждой привязке есть `downloadToClient`. У новой привязки загрузка по умолчанию выключена: правила встроены в полную подписку. При включении клиент получает удалённый набор. В обоих режимах `target` выбирается независимо: DIRECT, REJECT (блокировка), существующая группа/балансер или прокси. Смена доставки не меняет действие. DIRECT — только начальное значение; выключенная загрузка не подменяет выбранный REJECT или группу. Для совместимости у старой записи с `downloadToClient: false` и отсутствующим `target` применяется DIRECT. Явно пустое или некорректное действие сохраняется как черновик с предупреждением, не применяется молча. Прежние шаблоны без поля сохраняют прежнее действие и способ доставки.

Клиентский `clientRefreshIntervalSeconds` — целое число от 300 до 2592000, по умолчанию 86400. Он передаётся как `update_interval` sing-box либо `interval` HTTP rule-provider. Это расписание приложения, а не запрет его ручного обновления. Первая загрузка и использование кеша зависят от клиента. После изменения настроек обновите полную подписку.

DAT для sing-box преобразуется в JSON rule set, для Mihomo/Clash/Stash — в YAML classical provider. Ссылка подписана ключом панели и содержит формат/категории, но не адрес источника. Неподписанные изменения категорий или формата отвергаются. Нативные JSON/YAML/text могут встраиваться без URL; SRS остаётся удалённым бинарным набором. Для встраивания SRS импортируйте его исходный JSON. Xray JSON получает встроенные правила: стандартный geodata downloader обновляет уже существующие файлы и не обеспечивает первоначальную установку произвольного DAT во всех приложениях. В GUI неподдерживаемый переключатель недоступен с пояснением; API сохраняет такую конфигурацию как черновик с предупреждением.

Общая библиотека отдельно хранит HTTPS-источник и серверный график. Импорт по URL запоминает источник, но не включает автозагрузку без выбора администратора. Файлу с компьютера можно назначить URL. `PATCH /api/geofiles/:id/refresh` принимает `sourceUrl`, `enabled` и `intervalSeconds` (900–2592000). `POST /api/geofiles/:id/refresh` пытается проверить источник вручную и возвращает `updated`; обязательный интервал действует и для ручного повтора. Эти операции разрешены только администратору. Настройки библиотеки применяются сразу ко всем шаблонам с этим файлом и сохраняются в постоянном каталоге `backups/geofiles`.

Планировщик проверяет расписание раз в минуту, не более четырёх файлов за проход и двух параллельных загрузок. Межпроцессная блокировка и сохраняемая аренда предотвращают параллельную загрузку одного файла; перезапуск и отказ источника не сбрасывают интервал. Каждый запрос и переход повторно проверяют HTTPS/DNS, публичность адресов, ограничения размера, времени и формат. Изменённый DAT проверяется на категории действующих шаблонов до замены. Ошибка сохраняет последнюю исправную версию и показывает состояние в библиотеке.

Исходный URL с SHA-256 остаётся неизменяемым. Новые подписки используют `latest.ext` или подписанный производный URL с обязательной перепроверкой кеша; им не требуется получать новый URL после каждого серверного обновления. Хранятся исходный файл и не более двух обновлённых версий (до 6 GiB для 32 файлов максимального размера). Браузер/прокси не помечает изменяемые ресурсы как immutable. Кеш скомпилированных правил зависит от хеша активной версии. Режим без загрузки получает новые данные только при обновлении самой подписки.

При смене `APP_SECRET` обновите клиентские подписки: подписи старых производных URL перестанут действовать.

Форматы и ограничения: [sing-box rule sets](https://sing-box.sagernet.org/configuration/rule-set/), [Mihomo providers](https://wiki.metacubex.one/en/config/rule-providers/), [Stash inline и remote](https://stash.wiki/en/rules/rule-set), [Xray geodata](https://xtls.github.io/en/config/geodata.html).
