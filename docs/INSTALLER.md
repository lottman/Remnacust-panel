# Установка и обслуживание

## Обновление из панели

При наличии нового выпуска номер версии в верхней панели подсвечивается цветом темы. Нажмите на него и выберите «Обновить» под кнопками поддержки и GitHub. Кнопка появляется только при наличии обновления.

Для прежней установки сначала выполните `upgrade-panel` через новый установщик. Он устанавливает `remnacust-panel-update.service` и добавляет приложениям доступ к локальному сокету через каталог `/run/remnacust-control`, доступный только для чтения. Docker socket в панель не передаётся. На сервере без systemd остаётся обновление через команду `remnacust`.

Обновление разрешено только сеансу администратора; API-токены его запускать не могут. Все открытые сеансы блокируются до завершения. Закрытие вкладки не останавливает операцию. Установщик проверяет выпуск, создаёт копию базы и пересоздаёт приложения. Ноды, существующий reverse proxy, ключи и тома сохраняются. После проверки готовности браузер перезагрузит страницу. При ошибке проверьте журнал `panel-update-<идентификатор>.log` в каталоге `logs` установщика перед повтором. Интерфейс показывает восемь этапов, время и последние 24 события; оставшееся время оценивается только по данным прежней операции. [Прогресс и состояние](UPDATE-PROGRESS-AND-NODE-HEALTH.md).

## Установка

Скрипт находится в [`installer/installer.sh`](https://github.com/lottman/Remnacust-installer/blob/main/installer/installer.sh); полное руководство, команды, параметры, миграция и восстановление — в [`installer/README.md`](https://github.com/lottman/Remnacust-installer/blob/main/installer/README.md).

Запуск меню из консоли сервера:

```bash
curl -fsSL --proto '=https' --proto-redir '=https' https://github.com/lottman/Remnacust-installer/releases/latest/download/installer.sh -o installer.sh && sudo bash installer.sh
```

[Скачать installer.sh](https://github.com/lottman/Remnacust-installer/releases/latest/download/installer.sh). Установка, обновление и миграция доступны только на Ubuntu 22.04 LTS, 24.04 LTS и 26.04 LTS (amd64/arm64). На другой ОС приложение и системные пакеты не меняются.

Панель устанавливается через `install-panel`, нода с нашим Xray — через `install-node`. Обновление: `upgrade-panel` и `upgrade-node`. Enter в запросе версии выбирает `latest`; `--version 1.2.72` закрепляет выпуск установщика с панелью 1.1.7.41, нодой 1.1.15 и ядром 1.1.9. Все команды остаются видимыми в меню.

Переход с существующей Remnawave выполняется через `migrate-remnawave-panel` или `migrate-remnawave-node`. Установщик сохраняет проект Compose, инфраструктуру, секреты, сети и тома. Для панели требуется исходный `APP_SECRET`. Перед обновлением создаётся резервная копия; после миграций проверяется сохранность данных.

Перенос Marzban — `migrate-marzban-panel`: экспорт через API, предварительный отчёт (`--dry-run`), перенос ключей, сроков и статусов, проверка конфликтов. Это перенос пользователей в подготовленную панель; хосты, ноды и старые JWT-ссылки требуют настройки, описанной в руководстве.

Для выпуска публикуются `installer.sh`, `remnacust-source-vVERSION.tar.gz`, `remnacust-runtime-vVERSION.tar.gz`, шесть архивов образов (панель, нода и страница подписки для amd64/arm64) и `SHA256SUMS`. Исходники и помощники берутся из проверенного архива этого выпуска. Скрипт не зависит от файлового менеджера.

Установщик использует готовые образы GHCR с проверкой версии и архитектуры. Для новой панели HTTPS обслуживает Caddy в Docker, а не системный `nginx.service`. При обновлении или переносе существующей панели прежний Caddy/Nginx и его сертификаты сохраняются. Проверка контейнеров: `sudo remnacust status`.


## Закрепление выпуска и восстановление обновления

Служба обновлений 1.2.71 получает свежие метаданные Latest без повторного кешированного ответа, закрепляет один точный тег и использует его для проверки и установки. Запрошенная браузером версия — минимальная: более новая проверенная панель разрешена, более старая и понижение установленной версии запрещены. Версия установщика и версия панели различаются. Если старая служба уже завершила попытку с сообщением «В установщике ещё нет этой версии панели», обновите её один раз командой `sudo remnacust upgrade-panel --version 1.2.71`. Публикация нового выпуска сама по себе не заменяет службу на сервере.

## Права и очистка образов

При установке и обновлении ноды без подтверждённого `NET_ADMIN` установщик спрашивает о добавлении права. Уже действующее право сохраняется без повторного вопроса; проверяется эффективный `CapEff`, а не только запись в Compose. Для запуска без терминала используйте `--net-admin` или `--no-net-admin`. Сбор IP через Xray не требует этого права. Docker и Compose v2 устанавливаются при отсутствии; компиляция приложений на сервере не выполняется.

Очистка запускается после успешной проверки обновления. Она сохраняет текущий и предыдущий образы компонента и все образы, используемые контейнерами, включая остановленные. Чужие образы, тома и данные не удаляются; глобальный `prune` и принудительное удаление не используются. Если безопасная очистка не завершилась, она откладывается. Обновление контейнера ноды может прервать соединения; применение совместимой конфигурации через API ядра — отдельная операция.
