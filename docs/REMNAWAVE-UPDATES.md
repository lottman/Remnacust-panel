# Исправления из Remnawave

Remnacust 1.1.1 основан на backend/frontend Remnawave 3.4.4 и Node 3.4.1. В панель также включены два исправления из `backend/dev` от 27 сентября 2026 года.

## gRPC в подписке Xray JSON

[dec0fcc](https://github.com/remnawave/backend/commit/dec0fcca4e47f13e835ebe7466dab68911d03273) исправляет имя параметра: генератор выдаёт `grpcSettings.multiMode`, а не `grpcSettings.mode`. Значение берётся из настроек транспорта хоста. После обновления панели клиент должен заново получить подписку в формате Xray JSON.

## Фильтры ID

[814fb05](https://github.com/remnawave/backend/commit/814fb05460b0205a781635872e8934356e15185b) меняет поиск по числовым идентификаторам:

- ID пользователя и ID отчёта, пользователя или ноды в торрент-отчётах ищутся точным числом. Фильтр `12` больше не совпадает с `123` или `312`.
- Неверный ID возвращает пустой результат. Он не отключает фильтрацию и не выбирает записи с незаполненным Telegram ID.
- Корректный поиск части Telegram ID сохраняется.
- Большие ID передаются как `bigint`, без округления через JavaScript `Number`.

Миграция базы для этих исправлений не нужна. Формат API и собственная версия 1.1.1 сохраняются. Обновляется панель; установленную ноду или ядро ради этих двух изменений обновлять не требуется.

Во вкладке «Документация → Версии и совместимость» показаны оба перенесённых коммита с датой и ссылками на оригиналы. Названия переведены на русский, английский, персидский и китайский.
