# Проверка истории редакторов и UI — 18 октября 2026

## Исправления

- История профилей и шаблонов использует общий интерфейс: выбор версии, сравнение сохранённого кода с текущим черновиком, обновление списка и открытие версии в редакторе.
- Восстановление не сохраняет профиль автоматически. Замена несохранённого черновика требует подтверждения. Подтверждение сбрасывается при смене версии, изменении её содержимого после обновления списка или изменении черновика.
- Черновик профиля передаётся в историю без перерисовки всей страницы на каждое нажатие клавиши. Восстановление привязано к UUID профиля.
- Снимок черновика тоже привязан к UUID: переход между профилями при открытой истории больше не переносит в сравнение код предыдущего профиля.
- Общая оболочка страницы сохраняется при переключении mobile/desktop. Изменение ширины не должно сбрасывать вкладку истории и состояние форм; мобильное меню сохраняет закрытие по Escape и при навигации.
- Убраны вложенные рамки фокуса внутри searchable MultiSelect и служебных элементов Monaco. Основной фокус поля остаётся видимым.
- Сервисы documentSymbols, CodeLensCache, treeViewsDnD и diffEditor регистрируются до создания первого редактора. Исправлены ошибки отсутствующих сервисов при просмотре полной страницы.
- При закрытии истории модели сначала отсоединяются от сравнения, затем освобождаются. Это предотвращает ошибку `TextModel got disposed before DiffEditorWidget model got reset`, не оставляя модели в памяти.
- Возраст снимка трафика портов обновляется одним таймером активного редактора; устаревшие данные перестают отображаться как свежие без необходимости нового ответа сервера.
- В тесте HTTP/2 ядра создаётся новая конфигурация транспорта вместо копирования использованного mutex и обработчиков закрытия.

### C — Согласованность и регрессии

Файловый адрес получает конфигурацию без префикса `@`. При восстановлении служебные webhook из старого abstract-формата и нового приватного файлового формата переводятся на текущие адрес/токен. Пользовательские HTTP(S)-webhook и произвольные файловые адреса сохраняются; это проверено отдельно. Клиентские форматы не изменялись.

Настоящий перезапуск контейнера сначала воспроизвёл отказ cached-порта без панели; после исправления bootstrap автоматическое восстановление заработало. Проверены обычный служебный inbound и прямой API Lua-профиля: кешированное VLESS-соединение работает до новой команды панели, новый api.sock имеет режим 0600, последующее live-применение сохраняет PID и прежний поток. Пауза, отсутствие checkpoint, неподдерживаемое ядро, symlink/неприватный файл и отсутствие готового API дополнительно проверены регрессиями.

В ноду повторно упакованы актуальные исходники ядра. Архив содержит **1601 файл**; SHA-256 архива и каждого содержимого проверены, изменённые production-файлы сверены с checkout. README и документация совместимости/проверки запуска обновлены. Тег официального Xray v26.10.10 проверен через `git ls-remote`; развитие ветки main в качестве upstream baseline не добавлялось.

### E — Ограничения

Публичные DoH 1.1.1.1 и QUIC dns.adguard-dns.com в этом окружении не подтверждены. Независимый curl к 1.1.1.1 получил ошибку недоверенной цепочки TLS; проверка сертификата не отключалась. Локальный HTTP/2 DNS и остальные DNS-тесты прошли с race.

Контейнер сквозной проверки использовал runtime-слой прежнего выпущенного образа, текущие main.js и ядро, текущие init/run-скрипты и недостающие JS-зависимости из checkout. Это проверка текущего кода в настоящем runtime, **не** подтверждение заново собранного полного production-образа. Такой образ и новый выпуск по запрету пользователя не публиковались.

Не подтверждены все приложения и платформы клиентов, ARM64 на реальном оборудовании, длительный многонодовый нагрузочный E2E и окончательный SQL-координатор восстановления квот. Документация продолжает отмечать соответствующие готовящиеся функции как незавершённые. Проверка auth и защищённых маршрутов не доказывает всю бизнес-логику.

### F — Решение

**READY WITH RISKS для проверенных локальных исправлений ноды и ядра.** Это не гарантия отсутствия любых ошибок и не одобрение выпуска всей системы: для полного product-level sign-off остаются ограничения раздела E. Релиз и деплой не выполнялись.

После проверки подтверждено отсутствие контейнеров с меткой этого аудита и оставшихся процессов сценариев. Известные временные каталоги фикстур и локальный тестовый исполняемый файл ядра удалены; ранее существовавшие Docker-образы сохранены. Временные ключи создавались внутри тестовых каталогов, которые убирает smoke-harness. Исходные изменения и журналы проверок сохранены локально.
