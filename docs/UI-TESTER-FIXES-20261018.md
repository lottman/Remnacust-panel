# Исправления по отзывам тестера

- Все способы отбора поддерживают all/random/group; схема API, генератор и GUI синхронизированы. Для динамического отбора группы содержат UUID хостов, фильтр применяется до выбора.
- Переход на random/roundRobin удаляет относящиеся к балансеру ненужные пробы, сохраняет пробы других балансеров и произвольный код.
- В GUI leastLoad доступны expected/tolerance/baselines/maxRTT из существующего JSON, остальные параметры сохраняются.
- Подсказки mode/type/selectFrom/UUID/тегов работают в частично написанном JSON.
- Переключатели наследования лимитов показывают сохранённое состояние даже при отсутствии тега. Добавление тега само по себе не меняет значения.
- Общая тема TimePicker исправляет высоту/ширину выделенного сегмента времени во всех трёх формах истечения подписки.
- Необязательное назначение шаблона свёрнуто; DNS/routing GUI не добавлялся.

Доступ к одному хосту уже ограничивается в настройках хостов через внутренние сквады: целевому хосту разрешают нужный сквад, на остальных запрещают этот сквад либо не включают его в ALLOW_ONLY. Пользователь не должен иметь другой сквад, открывающий эти хосты: проверка разрешает доступ через любой подходящий сквад с нужным inbound. Сам выбор шаблона не ограничивает доступ.
