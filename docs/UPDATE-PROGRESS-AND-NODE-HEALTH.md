# Обновление и здоровье нод

В опубликованной панели доступны восемь этапов обновления панели, процент завершённых этапов, прошедшее время, число оставшихся этапов и журнал последних 24 событий. Журнал скачивается в JSON. Полный технический вывод остаётся в приватном файле на сервере; аргументы команд и секреты не публикуются в браузер.

Оценка времени появляется после успешного обновления с измеренными этапами. Если истории нет или текущая операция заняла больше прежней оценки, показывается число этапов. Во время перезапуска API окно сохраняет последний журнал и ждёт восстановления связи. Ошибки PANEL_UPDATING и сетевые ошибки в подтверждённом режиме обслуживания не создают повторных уведомлений; остальные ошибки отображаются.

Здоровье равно 0/100 для отключённой, недоступной или ещё подключающейся ноды, без активной конфигурации или свежего подтверждения работающего ядра. После подтверждения каждый из четырёх сигналов даёт 25 баллов. Отсутствие ресурсов снижает оценку до 75, не превращая неизвестные данные в успешные. Кеш uptime истекает через 16 секунд, ресурсов — через 30; отсутствие подтверждения не означает доказанное падение ядра. Ответ API очищает текущие метрики для недоступной ноды.

NET_ADMIN — право Docker, а не отдельный пакет. Интерактивное обновление проверяет CapEff процесса внутри текущего контейнера. Подтверждённое право сохраняется в Compose без повторного вопроса. При расхождении Compose и контейнера или невозможности проверки появляется пояснение и выбор. В установке без терминала право требует явного --net-admin; отказ по умолчанию совпадает с [n].

Установщик использует Docker Engine и Compose v2. Существующий Docker сохраняется. Если Docker отсутствует, пакеты ставятся из официального репозитория Docker для поддерживаемой Ubuntu. Приложения загружаются как готовые образы по закреплённым digest; исходники на VPS не собираются. Основной Compose обновляется с резервной копией и проверкой сохранности окружения, томов и инфраструктуры. Очистка образов сохраняет текущую и предыдущую версии.

Первоначальные изменения опубликованы в [1.2.64](https://github.com/lottman/Remnacust-installer/releases/tag/v1.2.64): панель 1.1.7.35, нода 1.1.12, ядро 1.1.7. [Сборка](https://github.com/lottman/Remnacust-installer/actions/runs/39161421401) завершилась успешно. Проверены 10 файлов выпуска, SHA256 и анонимное скачивание установщика и манифестов шести образов. На VPS этот прогон обновление не устанавливал.

Обозреватель сессий читает активные IP из Xray, включая персональные идентификаторы устройств и хостов. Нода включает наблюдение на каждом уровне политики независимо от NET_ADMIN. Ошибки API не превращаются в пустой успешный результат. Неполное сопоставление с пользователями и ошибки отдельных нод видны в интерфейсе и записи. Запись — периодический опрос: короткие подключения между опросами могут быть пропущены. Для применения исправления сбора требуется обновить ноду, а не только панель.


В текущем опубликованном комплекте 1.2.71 используются панель 1.1.7.40, нода 1.1.15 и Core/WASM 1.1.9. Сборка 1.2.64 выше — историческое свидетельство, а не номер последнего комплекта.
