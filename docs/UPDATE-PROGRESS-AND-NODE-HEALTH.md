# Обновление и здоровье нод

## Ход обновления

Окно обновления панели показывает восемь этапов, процент завершённых этапов, прошедшее время и последние 24 события. Оценка оставшегося времени появляется при наличии истории измерений. Без подходящей истории показывается число оставшихся этапов.

Закрытие вкладки не отменяет операцию. Во время перезапуска панели окно сохраняет последнее состояние и ждёт восстановления связи. После подключения проверьте итоговый статус.

Кнопка технического журнала скачивает файл **.log**, до **1 MiB** последних данных; обрезанный файл содержит уведомление. Полный журнал остаётся в закрытом каталоге сервера до замены следующей операцией. Сохраните нужный журнал перед повтором и удалите секреты перед передачей в поддержку.

Обслуживание системных пакетов с интерактивными вопросами выполняйте через SSH. Обновление компонента из панели может отложить такое обслуживание и сообщить об этом в журнале. Автоматической перезагрузки сервера нет.

## Связь и работа ядра

Доступность управляющего API и работа VPN-ядра проверяются отдельно. Доступный API с остановленным Xray не означает работоспособную ноду. При потере связи текущие показатели могут отсутствовать: неизвестное значение не означает нулевую нагрузку.

В карточке ноды проверяйте текущий адрес управления, время наблюдения и ошибки. При нескольких включённых адресах панель использует их порядок приоритета. Сохранённый SOCKS5 действует для всех адресов; ошибка прокси не вызывает прямое соединение в обход него. [Адреса и обслуживание](OPERATIONS.md).

## Оценка здоровья

Здоровье равно 0/100 для отключённой, недоступной или подключающейся ноды, без активной конфигурации либо свежего подтверждения работающего ядра. После выполнения этих условий каждый из четырёх сигналов даёт 25 баллов.

Отсутствие части ресурсных показателей может снизить оценку до 75/100 даже на работающем старом агенте. Оценка не заменяет проверку клиентского подключения. Данные обновляются с задержкой; после изменения дождитесь нового наблюдения.

Предупреждение об оплате использует дату связанной записи инфраструктуры и календарные дни UTC. У работающей подключённой ноды за три дня появляются жёлтые часы, за один день, в день оплаты и после срока — красные. Состояния ошибки, отключения и необходимости обновления имеют приоритет. Индикатор не выполняет платёж.

## Обновление компонентов

Панель, агент и Core обновляются отдельно. После обновления образа ноды ранее выбранное управляемое ядро может остаться активным. Проверьте фактически запущенную версию и поддержку нужных ограничений.

NET_ADMIN — право контейнера. Обычное чтение активных IP через Xray его не требует. Не включайте его для исправления ошибки управляющей связи. Для функций, которым это право требуется, используйте явный выбор установщика и проверьте применённую конфигурацию.

Установщик использует Docker Engine и Compose v2. Готовые образы загружаются без сборки на VPS. Перед обновлением сохраняются настройки; проверяйте свою внешнюю копию базы и окружения. Очистка образов сохраняет текущую, предыдущую и используемые контейнерами версии.

## Сессии

Список подключений читает наблюдаемые активные IP. Ошибка опроса отличается от успешного пустого результата. При частичном ответе проверьте список недоступных нод.

Запись подключений — периодический опрос, поэтому короткие соединения между снимками могут быть пропущены. Она не является журналом каждого пакета или посещённого сайта. [Запись подключений](SESSIONS-RECORDING.md).
