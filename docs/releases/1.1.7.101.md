# 1.1.7.101

Комплект: Panel/Page **1.1.7.101**, Node **1.1.26**, Core/WASM **1.1.16**, Installer **1.2.141**. Основа Xray — v26.10.31. Обновление серверов выполняется отдельно.

- Подписка с HWID больше не ждёт подтверждения нод. Состояние пользователя, блокировка устройства, срок и число устройств проверяются в БД. Новый ключ и задание доставки сохраняются атомарно; неудачная доставка повторяется. Обновление уже известного устройства не рассылает его ключ всему парку заново.
- В разделе «Настройка Xray» выбирается общее ядро панели: custom по умолчанию либо штатное default. Node содержит оба бинарных файла, редактор использует соответствующие WASM и схему. Стандартные функции сохраняются, зависимые от custom функции недоступны в default. Переключение проверяет настройки и постоянные журналы; несовместимые данные не стираются.
- Переход режима согласован с одновременными изменениями конфигурации в БД. Задание применения сохраняется и повторяется при временной недоступности очереди. Сохранение настройки не выдаётся за подтверждённое применение на нодах.
- Обновлены стабильные зависимости панели, страницы подписки, Node и редактора, включая Node.js 26.13 LTS, Prisma 7 и актуальные средства сборки. Сохранены ограниченные пулы соединений и параллелизм доставки.
- Исправлены временные значения в raw SQL для сеансов PostgreSQL с часовым поясом, отличным от UTC, и конкурентная публикация наборов геофайлов.
- Исправлены мобильные формы и размещение меню в режиме «Версия для ПК». Обновлены руководства, README и локализация RU/EN/FA/ZH.

Локальные проверки включают реальные миграции PostgreSQL 14–18, конкурентные запросы HWID, блокировки и срок доступа, оба валидатора Xray, типизацию, сборки и браузерные сценарии. Это не проверка всех версий сторонних приложений или гарантия отсутствия любых уязвимостей.

Перед обновлением сохраните БД, `.env`, `APP_SECRET` и постоянные тома. [Совместимость](../COMPATIBILITY.md) · [Резервные копии](../BACKUPS.md).

Проверка исходного архива включает обе WASM-сборки и все схемы. Сборка страницы подписки исключает локальные зависимости, секретные настройки и временные файлы из Docker context.
