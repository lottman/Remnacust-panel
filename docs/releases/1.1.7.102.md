# 1.1.7.102

Комплект: Panel/Page **1.1.7.102**, Node **1.1.26**, Core/WASM **1.1.16**, Installer **1.2.142**. Установка обновления на сервер выполняется отдельно.

- Добавлен редактор геофайлов. Загруженный файл можно изменить в общей библиотеке; готовый набор сохраняется отдельной копией с новым названием. Для DAT доступны категории и постраничное редактирование записей, для текстовых форматов — текст, для SRS — замена файла. Изменение защищено от перезаписи чужой версии по SHA-256.
- Под геофайлами можно добавлять собственные адреса: напрямую, блокировать или направлять через доступный выход/группу. Сохранены особенности пяти форматов шаблонов, включая `no-resolve`; собственный VPN-выход с именем DIRECT не подменяется встроенным действием.
- В автовыборе и геофайлах доступен импорт готовых JSON-правил Xray: объект, массив или фрагменты через запятую. Можно выбрать одно действие для всего списка либо сохранить маршруты из правил. Правила добавляются отдельно, без перезаписи остальных настроек; неподдерживаемые условия отклоняются целиком.
- Проверяются ссылки на категории при изменении и автоматическом обновлении файлов. Некорректные регулярные выражения и неоднозначные значения DAT проверяются с учётом поведения Go/Core. Ограничены размер, сложность, параллелизм и время загрузки; повреждённые изменения не заменяют рабочую версию.
- Исправлен кеш шаблонов при одновременном обновлении и сбоях Redis. Версия кеша изменяется в той же транзакции PostgreSQL, что и шаблон; старый процесс или запоздалое заполнение кеша не возвращает прежнюю конфигурацию после изменения. Одновременные чтения сырого шаблона объединяются без объединения персональных HWID, прав и выдачи геофайлов.
- Исправлены большие списки адресов, копирование бинарных наборов с длинным списком категорий, очистка временных данных при ошибках записи и раскрытие ключей подписки в путях ошибок. Обновлены документация и четыре языка интерфейса.

Для базовых профилей сохраняется совместимость с подтверждёнными штатными Remnawave-нодами и прежними страницами подписки. Новые серверные ограничения требуют соответствующих возможностей Node/Core. Этот выпуск не меняет их протокол и не требует замены Node/Core ради редактора геофайлов.

Проверки включают тесты backend/frontend, отдельный Redis, транзакции и миграции PostgreSQL 14–18, настоящий Core для regexp/DAT и браузерные сценарии. Это не проверка всех версий сторонних приложений и не гарантия отсутствия любых уязвимостей. Перед обновлением сохраните БД, `.env`, `APP_SECRET` и постоянные тома.
