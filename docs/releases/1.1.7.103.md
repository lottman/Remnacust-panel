# 1.1.7.103

Panel/Page 1.1.7.103; Node 1.1.27; Core/WASM 1.1.17 на основе Xray v26.11.9; Installer 1.2.149.

- Содержимое объединённого DAT входит в подписанный адрес. Изменение геофайла больше не оставляет клиенту тот же адрес старой копии. Повторная выдача неизменённого файла стабильна; старые ссылки и .sha256 совместимы. После обновления обновите подписку в приложении.
- Явный `/json` имеет приоритет над определением браузера. Throne 1.x с поддержкой массивов Xray JSON получает JSON на базовой ссылке при включённой настройке. Явные форматы и запреты доступа сохраняются.
- Основной домен можно оставить открытым, закрыть для прямых запросов или перенаправлять на выбранный дочерний CDN. Сначала настройте индивидуальный секретный заголовок CDN. Общий список доменов не содержит секретов.
- Core переносит официальный выпуск v26.11.9 с сохранением лимитов, автономности и совместимости старых конфигураций. Новые слоты XDRIVE включаются `useSlots`; по умолчанию сохранены старые сегменты. Редактор содержит согласованные custom/default валидаторы.
- MPTCP в Core остаётся выключенным по умолчанию. Это не исправление ядра Linux; статус CVE-2026-98432 проверяется отдельно у поставщика ОС.

## English

DAT content changes rotate its signed download address while unchanged content, previous URLs and .sha256 remain compatible. Refresh subscriptions after upgrading. Explicit JSON routes override browser detection; supported Throne 1.x clients can receive base-path JSON without bypassing access rules. Domain access supports direct, CDN-only and selected-CDN redirects with distinct private origin credentials. Core/WASM uses official Xray v26.11.9; XDRIVE slots are opt-in to retain legacy peers. MPTCP stays disabled by default, and Linux kernel remediation remains a separate operation.
