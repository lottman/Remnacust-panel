# 1.1.7.104

Panel/Page **1.1.7.104**, Node **1.1.27**, Core/WASM **1.1.17**, Installer **1.2.150**.

- Прежний основной домен можно удалить после явного подтверждения перевода его пользователей на текущий домен по умолчанию. Изменение привязок и удаление атомарны; ключи, устройства, заморозка, сроки и лимиты сохраняются.
- Режим «Закрыт» возвращает HTTP 403 без перенаправления. Основной домен закрывает всю свою CDN-семью; отдельный CDN — только свой адрес. Правильный CDN-заголовок не обходит блокировку.
- Последний работающий основной домен нельзя закрыть или удалить. Дочерние CDN защищены от случайного удаления вместе с основным доменом.
- Карточка пользователя и API ссылок скрывают недоступные адреса, включая основные домены с перенаправлением или доступом только через CDN. Общий QR использует доступную ссылку; пустой список больше не возвращает старый закрытый адрес.
- Добавлена 198-я миграция. Исправления DAT, JSON и Xray v26.11.9 из 103 сохранены. Обновление панели не заменяет ядро Linux и удалённые ноды.

## English

Adds atomic user reassignment when retiring a former primary, explicit BLOCKED mode for primary families and individual CDNs, and protection for the last available primary. User cards, QR codes and link APIs omit unavailable, CDN-only and redirecting primary addresses. An empty result cannot restore a legacy closed URL. Includes migration 198; preserves the DAT/JSON and Xray v26.11.9 changes from 103.
