# 1.1.7.107

- Исправлено отключение последнего кастомного геофайла: при обновлении подписки ранее выданный профиль провайдера получает пустые URL и списки правил вместо сохранения старого DAT.
- Очистка привязана к провайдеру и зарегистрированной идентичности клиента. Новый клиент без прежнего профиля не получает принудительное переключение маршрутизации.
- Ручные правила JSON, заголовки маршрутизации и сторонние профили сохраняются. Неизменённый сброс имеет стабильную ревизию; повторное включение файлов повышает её.
- Ожидание хранилища при очистке ограничено; его сбой не блокирует получение подписки.
- Документация обновлена на четырёх языках.

Для применения клиент должен обновить подписку. Доставку заголовков и конкурентные ревизии проверяют автоматические тесты; поведение кэша конкретного приложения требует проверки на устройстве.
