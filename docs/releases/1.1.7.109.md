# Panel / Subscription Page 1.1.7.109

## Геофайлы

- Общий порог встроенных правил настраивается в разделе «Геофайлы»: целое число от 1 до 50 000, по умолчанию 20 000. Это число адресов/условий, а не строк JSON.
- Сохранённый порог действует для всех шаблонов при следующем обновлении подписки. Повторное сохранение шаблонов не требуется. Настройки и кэш не смешиваются между одновременными запросами.
- Пределы размера профиля, полного ответа, компиляции и сложности остаются независимыми. Поддерживаемые клиенты могут перейти на DAT раньше порога; остальные получают совместимые встроенные правила в пределах своих бюджетов. Правила не обрезаются.
- Проверки категорий удалённых файлов имеют отдельный кэш до 32 записей и не вытесняют готовые встроенные правила. Это устраняет повторную компиляцию при большом числе файлов.
- Кэш компиляции использует LRU и ограничен 32 наборами, 250 000 условиями и 16 MiB текста условий. Эти значения ограничивают данные кэша, а не весь heap процесса. Сборка DAT сохраняет отдельный ограниченный кэш и очередь.
- При выключенной автоматизации явно прописанные администратором `geodata`, `geosite:`, `geoip:`, `ext:` и заголовок `routing` сохраняются. Отключённые назначения библиотеки не обрабатываются, фоновое обновление не запускается; явное обновление администратором доступно.

## Совместимость

Настройка хранится в новой миграции БД с проверкой диапазона; изменения используют существующее поколение кэша. Старые записи получают 20 000. В API PATCH поле `geofilesInlineRuleLimit` необязательно; пропуск поля не изменяет значение. Права API не расширены.

Node 1.1.27 и Core/WASM 1.1.17 не менялись. Согласованный комплект — Installer 1.2.155. Публикация не обновляет установленный сервер автоматически.

## English

A shared inline threshold is available under Geofiles: 1–50,000 addresses/conditions, default 20,000. Save it and refresh the subscription; templates do not need to be saved again. Independent size and complexity limits remain in effect, and unsupported clients retain compatible inline delivery within their budgets. Manual geodata and routing remain untouched when automation is disabled.

Remote category checks use a separate bounded cache and no longer evict hot inline rules. The compiled-rule cache now uses LRU with separate entry, matcher-count and text-byte bounds. The new database column has a range constraint and uses the existing cache generation. API PATCH accepts the optional `geofilesInlineRuleLimit` field without changing permissions. Node/Core versions are unchanged.

## Проверки

200 миграций применены в GitHub Actions на PostgreSQL 14.24, 15.19, 16.15, 17.11 и 18.6 под ролью без superuser/createdb/createrole. На каждой версии прошли проверки диапазона порога, отката, конкурентных изменений и поколения кэша. Это проверка изолированных баз CI, а не производственного сервера.
