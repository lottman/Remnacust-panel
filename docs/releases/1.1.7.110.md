# Panel / Subscription Page 1.1.7.110

## Геофайлы и подписки

- Настраиваемый порог встроенных правил: 1–250 000 адресов/условий, по умолчанию 20 000. Независимые ограничения размера, компиляции и сложности сохраняются; переход на DAT может произойти раньше. Правила не обрезаются.
- Ссылки GeoIP/GeoSite проверяются и в массивах, и в строковых списках через запятую, включая DNS. Отсутствующая или неоднозначная категория не выдаётся как рабочая конфигурация. Элементы массивов и regexp с запятыми сохраняются без разделения.
- При заполнении служебного хранилища небольшие выборки категорий остаются в подписанной ссылке. Если выборка не помещается в безопасную длину URL, используется совместимый полный DAT. Старые подписанные ссылки и обновление содержимого поддерживаются.
- Выключенная автоматизация сохраняет явные ручные правила и ссылки администратора. Старые приложения не получают неподдерживаемые механизмы загрузки DAT. Несовместимые share-link хосты пропускаются без автоматических профилей-заглушек; вручную сохранённые примечания не удаляются.

## Редактор и CDN

- Подсказка на UUID хоста работает в JSON/YAML, назначениях, группах, селекторах, ссылках `host:UUID` и сравнении истории. Она использует уже загруженный список; скрытые от этого списка и удалённые хосты не раскрываются. Поддерживается копирование, поиск автодополнения по UUID и названию. Разбор ограничен документом до 2 MiB; длинные поля сокращаются.
- Каждое открытие окна CDN-реквизитов создаёт отдельный запрос без кэша. Закрытие отменяет запрос и удаляет частную запись из кэша. Просмотр не меняет сами ключи CDN.
- Устаревшие локальные патчи deepmerge и адаптера Zod заменены поддерживаемым адаптером `nestjs-zod` 5.6.0. Существующие проверки входных данных и прав сохраняются.
- Руководство обновлено на RU/EN/FA/ZH.

## Обновление

Согласованный комплект: Installer **1.2.156**, Panel/Page **1.1.7.110**, Node **1.1.28**, Core/WASM **1.1.17** на Xray **26.11.9**. Обновите отдельно установленную страницу подписки вместе с панелью. Сохраните `.env`, `APP_SECRET` и резервную копию БД. Новая миграция расширяет диапазон настройки, не меняя сохранённое значение или значение по умолчанию. Обновление панели не заменяет удалённые ноды.

## English

The inline preference now accepts 1–250,000 conditions, default 20,000, while independent safety budgets remain enforced. DAT references are validated in arrays and comma-separated routing/DNS StringLists. Compact signed selections preserve subsets when manifest storage is full; older URLs and refresh behavior remain supported. Disabled automation preserves manual settings.

CDN credential views use isolated fresh requests and discard private cached data on close without rotating keys. The maintained Zod adapter replaces obsolete local patches. Documentation covers all four UI languages. Update the separate subscription website with the panel and retain existing secrets and database backups.
