# Panel / Subscription Page 1.1.7.111

## Геофайлы

- Порог 1–250 000 условий, по умолчанию 20 000 включительно, применяется отдельно к каждому итоговому профилю хоста. Условия соседних хостов и вариантов шаблона не суммируются.
- Исправлена повторная генерация всей подписки в режиме DAT из-за одного большого профиля. Небольшие профили сохраняют встроенные правила; в подписанные DAT входят только категории, использованные в итоговой выдаче.
- Удалён прежний дополнительный порог переключения 90 000 байт. Независимый защитный предел профиля 900 000 байт после форматирования и раскрытия StringList сохраняется и может сработать раньше порога условий. Общий ответ ограничен 16 MiB. Правила не обрезаются.
- Проверка выполняется после добавления ограничений хоста и построения автовыбора. Ошибка одного профиля не выдаёт частичную подписку. Изменение порога и переход обратно во встроенные правила обрабатываются при следующем обновлении подписки.
- Включение GEO перенесено в меню ⋯ каждого шаблона; состояние видно по обычному или перечёркнутому значку. Общий переключатель удалён. Новые шаблоны выключены, миграция 202 сохраняет прежнее состояние существующих шаблонов. JSON на базовом пути остаётся обязательным; его нельзя выключить, пока включён хотя бы один шаблон. Ручные правила администратора сохраняются.
- Руководство и подсказки обновлены на RU/EN/FA/ZH, добавлен пример назначения автовыбора.

## Интерфейс и нагрузка

- Убрано увеличение и уменьшение иконок при нажатии. Анимации работают с внутренними линиями SVG; соблюдается уменьшение движения, ресурсы освобождаются при скрытии страницы.
- Каталог назначений шаблонов больше не читается полностью из PostgreSQL на каждый запрос подписки: используется ограниченный кэш с проверкой поколения и объединением одновременных загрузок. В тесте 100 параллельных выдач вызывают одну загрузку каталога, сохраняя 100 независимых проверок доступа и лимитов. Это не измерение нагрузки реального сервера; тяжёлый SQL клиента требует отдельного плана выполнения.

## Проверка безопасности upstream

Сверены официальные изменения Backend/Frontend 3.4.7–3.4.9, Node 3.4.3–3.4.5 и Xray v26.11.9, а также опубликованные advisories. Исправления sirv и чтения сертификатов из [Backend 3.4.8](https://github.com/remnawave/backend/releases/tag/3.4.8) уже присутствуют и проверены регрессионными тестами. Защита от обхода авторизации backend-tools при изменении регистра URL и от гонки регистрации HWID сохранена. Core содержит исправление проверки имени при закреплении CA-сертификата и отключает MPTCP по умолчанию. Нода сохраняет Lua routing через приватный API-сокет. Это не означает перенос всех новых функций upstream.

[CVE-2026-98432](https://access.redhat.com/security/cve/cve-2026-98432) относится к ядру Linux хоста. Обновление контейнера не заменяет исправленное ядро и его загрузку после перезагрузки. Состояние ОС установленного сервера в этом выпуске не проверялось и не изменялось.

## Обновление

Комплект: Installer **1.2.157**, Panel/Page **1.1.7.111**, Node **1.1.28**, Core/WASM **1.1.17**, Xray **26.11.9**. Обновите отдельно установленную страницу подписки вместе с панелью, сохранив `.env`, секреты и резервную копию. Серверы пользователя при подготовке выпуска не изменялись.

## English

The configurable inline threshold (1–250,000 conditions, default 20,000 inclusive) now applies independently to each final host profile and template variant. Only oversized profiles switch to DAT; smaller profiles remain inline. The obsolete 90,000-byte switching threshold has been removed, while the independent 900,000-byte formatted profile budget and 16 MiB response cap remain enforced. Final host rules and autoselect output are included in validation; failures never produce partial subscriptions. Settings and manual rules are preserved. Migration 202 moves enablement to each template, preserves existing state and defaults new templates to off. The template menu and normal/crossed-out icon expose the state. JSON at the base path remains required.

Icon feedback now animates SVG details without scaling or moving the glyph. A generation-bound bounded assignment catalogue cache coalesces concurrent full-template reads while keeping user authorization, HWID and quotas per request.

Official upstream fixes and published advisories were compared with our sources and focused regressions. Existing sirv, certificate-read, tools-authentication, HWID-registration, CA-pinning and Lua-routing protections remain in place. The Linux kernel CVE requires a separately patched host kernel; no production server was inspected or updated for this release. Update the separate subscription website with the panel.
