# Remnacust Panel / Page 1.1.7.113

- Создание пользователя после включения и снятия «Отключить лимит HWID» снова использует общий лимит. Очистка поля также не отправляет недопустимый `null`; явный ноль и числовой лимит сохраняются. Обновление существующих пользователей по-прежнему поддерживает сброс к общему лимиту.
- `{{SUBSCRIPTION_URL}}` и стандартный `profile-web-page-url` сохраняют проверенный публичный домен текущего запроса, включая CDN и его путь. Административные операции без публичного запроса сохраняют назначенный домен. Явно заданные постоянные URL не переписываются.
- Общие окна поиска получили согласованные строки, компактные статусы и ограничения ширины. UUID остаются доступны для поиска, но не перегружают строки результатов. На узких экранах статусы помещаются; индикатор состояния больше не создаёт вложенную кнопку.
- Проверка наличия выданных идентичностей использует ограниченный индексный поиск вместо чтения всей таблицы. Проверки прав, HWID, квот и статуса выполняются заново; кэш разрешений не добавлен. Улучшение отдельного SQL-запроса не означает одинакового времени ответа для всех подписок.
- Совместимый комплект: Installer 1.2.160, Node 1.1.30, Core 1.1.18 / Xray v26.11.9. Node 1.1.30 исправляет первое применение обычного профиля после восстановления checkpoint с проверкой запуска и отката. Панель не обновляет удалённые ноды автоматически.

## English

User creation now handles enabling and then clearing Disable HWID Limit correctly: blank/inherited values are omitted, while explicit zero and positive limits are preserved. Existing-user updates retain their reset semantics.

Subscription URL variables and the default profile-web-page-url header retain the validated public request domain, CDN and path. Administrative calls without public request context still use the assigned domain. Explicit literal administrator URLs are unchanged.

Shared search dialogs use consistent compact rows, responsive widths and non-interactive status indicators. UUID filtering remains available. Host identity metadata uses bounded indexed lookups without caching authorization or changing access decisions.

The matching bundle is Installer 1.2.160, Node 1.1.30 and Core 1.1.18 / Xray v26.11.9. The node fixes initial ordinary profile application after checkpoint recovery with checked rollback. Updating the panel does not update remote nodes automatically.
