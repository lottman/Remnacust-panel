# Remnacust Panel / Page 1.1.7.114

- Карточки хостов повторно открываются без зависания на загрузке: каждый показ получает свежие данные, закрытые карточки не создают фоновый опрос.
- Подсказки UUID хостов в редакторе показывают ограниченные локализованные параметры вместо технического JSON. Данные хостов экранируются; HTML и команды не выполняются.
- Схемы редактора распознают служебный раздел remnacust и проверяют ссылки на геофайлы вместе с параметрами инжектора и Xray.
- Смена стратегии балансера удаляет несовместимые параметры прежнего алгоритма. Повторный выбор leastPing исправляет оставшиеся параметры leastLoad; порядок roundRobin сохраняется.
- Конечный числовой tolerance не вызывает лишнего предупреждения: Xray ограничивает его диапазоном 0–1, исходный JSON сохраняется. Неверные типы, бесконечные значения и ошибки ссылок остаются ошибками.
- Ошибки API и редактора переведены на понятный язык; конфликт имени inbound сохраняет причину ошибки. Метаданные домена пользователя совпадают с публичной ссылкой, включая доступный CDN.
- Документация и переводы согласованы для русского, английского, персидского и китайского языков.
- Комплект: Installer 1.2.162, Node 1.1.30, Core 1.1.18 / Xray 26.11.9. Удалённые ноды автоматически не обновляются. Installer распознаёт устаревшие локальные образы с подтверждённой меткой происхождения и сохраняет используемые контейнерами, текущий и предыдущий образы. Резервные копии автоматически не удаляются.

## English

Host cards reliably reopen with fresh data, including cancellation and rapid switching. Host UUID previews show escaped localized parameters instead of raw JSON. The editor recognizes remnacust metadata and validates geofile references together with injector and Xray fields.

Changing a balancer strategy removes incompatible settings; reselecting leastPing repairs older leftovers while roundRobin ordering and unrelated routing are preserved. Finite tolerance follows native clamping without a redundant warning; invalid types, nonfinite values and broken references remain errors.

Human-readable localized API errors retain inbound conflict reasons. User domain metadata matches its public subscription URL, including an available CDN. Documentation and translations cover ru/en/fa/zh.

Bundle: Installer 1.2.162, Node 1.1.30, Core 1.1.18 / Xray 26.11.9. Remote nodes are not upgraded automatically. Image cleanup recognizes verified local builds and preserves running/stopped container references and rollback images; database backups are not automatically deleted.
