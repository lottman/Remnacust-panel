# Remnacust Panel / Page 1.1.7.115

- Поиск нод находит дополнительные IPv4 и IPv6, включая частичный ввод. Имя, UUID, основной адрес и провайдер по-прежнему участвуют в поиске.
- Иконка поиска выровнена по центру поля во всех общих окнах поиска. Проверены узкий экран, светлая и тёмная темы, направление справа налево.
- Основной IP не дублируется в дополнительных адресах карточки и таблицы. Эквивалентные записи IPv6 распознаются. Скрытие не меняет записи БД, статусы или порядок маршрутов; редактирование и сортировка дополнительных IP сохраняют скрытую запись.
- Включены подготовленные исправления 114: повторное открытие карточек хостов, безопасные локализованные подсказки UUID, схема remnacust, очистка несовместимых настроек при смене стратегии балансера и корректная проверка tolerance.
- Включены понятные ошибки API и редактора и согласованные метаданные публичного домена пользователя. Документация и существующие переводы ru/en/fa/zh проверены.
- Комплект: Installer 1.2.163, Node 1.1.30, Core 1.1.18 / Xray 26.11.9. Изменения панели не обновляют удалённые ноды. Очистка образов в установщике сохраняет используемые и откатные образы; резервные копии не удаляются.

## English

Node search now matches additional IPv4 and IPv6 addresses, including partial queries. Search icons remain vertically aligned on desktop and mobile. The primary IP is omitted from additional-address views without deleting stored entries or changing statuses and route order. Equivalent IPv6 spellings are handled, and editing or sorting additional addresses preserves hidden primary entries.

Includes the prepared 114 fixes for reopening host cards, escaped localized host previews, remnacust editor metadata, strategy-specific balancer settings and numeric tolerance validation. Human-readable API/editor errors and consistent public-domain metadata are included. Documentation and existing ru/en/fa/zh translations are checked.

Bundle: Installer 1.2.163, Node 1.1.30, Core 1.1.18 / Xray 26.11.9. Remote nodes are not upgraded automatically. Installer image cleanup preserves referenced and rollback images and does not delete backups.
