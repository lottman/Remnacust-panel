# Remnacust Panel / Page 1.1.7.116

- Блокировка и разблокировка HWID подтверждают сохранение состояния вместе с заданием применения. Недоступная нода больше не превращает успешное сохранение в A261. Отмена доступа доставляется с повторами; без персональных ключей изолированная блокировка по-прежнему запрещена.
- Если статистика временно недоступна, а авторизованный API подтверждает остановленное ядро, панель повторно отправляет профиль с учётом задержки применения. Работающее ядро ради метрик не перезапускается.
- Предпросмотр подписки устройства свёрнут по умолчанию. «Убрать» отменяет запрос и очищает результат; приватная конфигурация не остаётся в кэше закрытого предпросмотра.
- Закрытие окон дожидается обратной анимации; запоздалое завершение не удаляет повторно открытое окно.
- Срок показывается точным числом дней. Замороженная дата имеет обычный вид, недоступна для редактирования и выделена синим; окончание — красным, последние три дня — жёлтым.
- Compose ноды использует публичный ghcr.io/lottman/remnacust-node:latest без входа в Docker и сохраняет состояние ядра, политик и runtime в постоянных томах. Не подключайте пустые тома поверх единственной копии состояния существующей ручной установки без резервной копии и переноса данных.
- Справка и локализация ru/en/fa/zh согласованы. Комплект Installer 1.2.164 включает Node 1.1.31, Core 1.1.19 и оба ядра на Go 1.27.4 для устранения GO-2026-6859. Обновление панели не обновляет удалённые ноды или отдельно закреплённое managed-ядро.

## English

HWID changes persist atomically with reconciliation work instead of reporting a node delivery failure after a successful save. Isolated blocking still requires personal device credentials. Authenticated health can schedule a profile for an explicitly stopped core when telemetry fails, while preserving running sessions and retry delays.

Device previews start collapsed and can be cleared or cancelled without retaining the result after closure. Modal cleanup waits for exit transitions and cannot remove a reopened window. Expiry uses exact day counts and consistent frozen, expiring and expired colors.

Manual Compose uses the public latest image and stable core, policy and runtime volumes. Existing manual deployments must back up and migrate their only state copy before adding empty mounts. The four operator languages are updated. Installer 1.2.164 includes Node 1.1.31 and Core 1.1.19 built with Go 1.27.4 to address GO-2026-6859; remote nodes and independently pinned managed cores require separate updates.
