# Remnacust 1.1.7.117

## Русский

- Исправлена ошибка A039 после успешной заморозки пользователя. Включение, отключение и восстановление доступа после продления или сброса трафика также не зависят от немедленного ответа всех нод.
- Изменение статуса или срока атомарно сохраняется с заданием применения. При недоступности ноды панель повторяет сверку после восстановления связи и своего перезапуска. Это работает и без зарегистрированных устройств. Старое задание не удаляет более новое изменение; повторы ограничены по параллельности.
- Заморозка сохраняет оставшееся время; повторная заморозка не добавляет срок. Активация возобновляет отсчёт. Исчерпанный срок и квота сохраняют ограничения.
- Описания известных ошибок API проверены для русского, английского, персидского и китайского. Код в скобках сохраняется для диагностики; приватные ответы сервера не показываются вместо описания.
- Обновлена справка администратора на четырёх языках; исправлена ошибка генератора справки.

Сохранение статуса не подтверждает немедленное прекращение соединений на физически недоступной ноде. Изменения требуют миграции `20261112010000_user_access_reconciliation`; пользователи, ключи, профили и настройки не удаляются. Панель не обновляет удалённые ноды автоматически.

## English

- Fixed A039 after a successfully saved user freeze. Enabling, disabling and restoring access after an extension or traffic reset also no longer depend on every node replying immediately.
- Status and expiry changes persist atomically with application work. Reconciliation retries after connectivity returns and survives panel restarts, including users without registered devices. Stale jobs cannot remove newer work; concurrency is bounded.
- Freezing preserves the remaining lifetime, repeated freezes add no time, and activation resumes the countdown. Expiry and exhausted quota continue to restrict access.
- Known API error descriptions were checked in Russian, English, Persian and Chinese. Diagnostic codes remain available without replacing explanations with private server responses.
- Updated the four operator guides and repaired their generator.

Saving a status does not confirm immediate termination of connections on an unreachable node. Migration `20261112010000_user_access_reconciliation` is required; users, keys, profiles and settings are retained. Remote nodes are not updated automatically.
