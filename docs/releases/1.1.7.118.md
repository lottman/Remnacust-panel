# 1.1.7.118

- Исправлено сохранение даты автоматической разморозки при создании и редактировании пользователя, а также в обеих массовых формах. Выбранные часы и минуты сохраняются с учётом часового пояса. Для новой даты предлагается текущее локальное время вместо полуночи; сохранённая дата остаётся доступна только для просмотра.
- Кнопки создания профиля и внутреннего сквада, фрагментов конфигурации и выбора inbound получили названия для экранных дикторов.
- Исправлены отсутствующие схемы редакторов Mihomo и sing-box. Подсказки загружаются из локальной сборки; версии ресурсов меняются при изменении содержимого. Повторное открытие sing-box использует общий кэш схем без изменения сохранённых шаблонов.
- Исправлено падение карточки пользователя после просмотра настроек доменов. Оба экрана используют один формат данных в кэше; изменение доменов обновляет список в формах пользователей.
- В стандартных Compose и новых установках используется PostgreSQL 18.6 с актуальными исправлениями безопасности. Обновление панели через установщик сохраняет образ и том существующей БД; её обновление выполняйте отдельно после резервного копирования, в пределах той же основной версии. Не подключайте том к другой основной версии PostgreSQL.
- Сохранены автоматическая разморозка, повторная доставка доступа на ноды и миграции 203–204 из предыдущего выпуска. Новых миграций в этом исправлении нет. Обновление удалённых нод и отдельно установленной страницы подписки выполняется отдельно.

## English

- Fixed automatic activation dates in user creation, editing and both bulk forms. Local hours and minutes survive timezone conversion. New dates start with the current local time instead of midnight; saved deadlines remain read-only.
- Added accessible names to profile/squad creation, configuration snippets and inbound selection buttons.
- Restored missing Mihomo and sing-box editor schemas as bundled local assets with content-versioned URLs. Reopening sing-box uses the shared schema cache without changing saved templates.
- Fixed user forms crashing after visiting domain settings. Both screens share one cached response format; domain changes refresh the user-form list.
- Standard Compose files and fresh installations use PostgreSQL 18.6 with current security fixes. Installer panel upgrades preserve the existing database image and volume. Update the database separately after taking a backup, within its current major version; never attach its volume to another major version.
- Retains automatic activation, durable node access reconciliation and migrations 203–204 from the previous release. This patch adds no migration. Remote nodes and separately installed subscription websites require separate updates.
