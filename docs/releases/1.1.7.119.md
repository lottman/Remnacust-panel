# 1.1.7.119

- Исправлено восстановление стандартных GeoIP/GeoSite в Happ и INCY после полного отключения кастомных DAT в подписке, а также при возврате всех её профилей к обычным правилам. Вместо пустых URL ранее выданный профиль получает стандартные источники Loyalsoldier/v2ray-rules-dat и новую ревизию. Обрезка файлов отключается, чтобы сохранить категории ручных правил JSON.
- Новая подписка без истории автоматических DAT не получает лишнюю загрузку. Пока в подписке используется хотя бы один кастомный DAT, стандартные источники его не заменяют. Явный заголовок routing и ручная секция geodata сохраняют приоритет.
- После обновления панели обновите подписку в приложении, дождитесь успешной загрузки файлов и переподключите VPN. Это загрузка стандартного набора, а не возврат точных встроенных файлов конкретной версии приложения. При сетевой ошибке восстановление ещё не завершено. Если история профиля или устройства на сервере утрачена либо имя изменилось, восстановите штатные геофайлы средствами приложения.
- Обновлено руководство на русском, английском, персидском и китайском. Новых миграций и изменений настроек оператора нет. Удалённые ноды и отдельно установленная страница подписки не обновляются автоматически.

## English

- Fixed standard GeoIP/GeoSite recovery in Happ and INCY after all custom DAT files in a subscription are disabled or all its profiles return to inline rules. Previously issued profiles receive the standard Loyalsoldier/v2ray-rules-dat sources and a newer revision instead of empty URLs. File trimming is disabled to preserve categories referenced by manual JSON rules.
- Fresh subscriptions without managed DAT history receive no unnecessary downloads. Standard sources do not replace a custom DAT still used by any subscription profile. Explicit routing headers and manual geodata sections retain precedence.
- After updating the panel, refresh the subscription, wait for successful file downloads and reconnect the VPN. This downloads a standard dataset, not the exact bundled files of a particular app version. Recovery is incomplete after a download failure. If server-side profile/device history is missing or the name changed, restore standard geofiles using the app.
- Updated the Russian, English, Persian and Chinese guides. No new migration or operator-setting change. Remote nodes and separately installed subscription pages require separate updates.
