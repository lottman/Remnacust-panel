# 1.1.7.121

- Общий выключатель системы геофайлов в дополнительных настройках подписки по умолчанию выключен. Для включения нужен JSON на базовом пути. Предпочтения шаблонов сохраняются, значки и команды скрыты при выключенной системе. Ручные правила и источники администратора сохраняются.
- Стандартные GeoIP/GeoSite Loyalsoldier доступны для загрузки в общую библиотеку и обновления с GitHub; у каждого файла своё расписание от 15 минут до 30 дней. Фоновые обновления работают только при включённой системе.
- Ранее выданные автоматические DAT восстанавливаются стандартными источниками и при ответе Base64. Автоматические профили отключают повторную обрезку DAT клиентом. Восстановление зависит от успешной загрузки приложением и сохранённой истории; ручные источники имеют приоритет.
- Выбор категорий больше не расширяется до полного файла при заполнении хранилища подборок. Удаление проверяет все источники подписанного составного файла. Проверка больших загрузок не блокирует цикл событий на всё время обработки.
- При вставке основного IP в новую дополнительную строку поле остаётся доступным для исправления. Статусы адресов сохраняются; основной IP не дублируется в списке дополнительных.
- Запоздалые ответы настроек не возвращают старое состояние общего переключателя. Фоновая смена метаданных файла не сбрасывает введённый интервал обновления.
- Исправлены транзитивные зависимости basic-ftp: версия 6.2.6 закрывает GHSA-5pm8-86m8-9m6r и GHSA-r4jh-29pc-gfqr. Новых прав доступа или публичных endpoints не добавлено.
- Документация и интерфейс обновлены на RU/EN/FA/ZH. Миграция БД: 205. Комплект: Installer 1.2.169, Node 1.1.32, Core 1.1.19 / Xray 26.11.9.

## English

- Added a geofile master switch in additional subscription settings, off by default and requiring base-path JSON. Template preferences remain saved; icons and commands hide while off. Explicit administrator rules and sources remain intact.
- Standard Loyalsoldier GeoIP/GeoSite sources can be downloaded into the library and updated from GitHub, with individual schedules from 15 minutes to 30 days. Scheduled updates require the master switch.
- Previously managed DAT recovery also works with Base64 responses. Automatic profiles disable repeated app-side trimming. Recovery requires successful app downloads and retained profile history; explicit manual sources take precedence.
- Saturated selection storage never widens selected categories to full-file delivery. Deletion checks every signed-bundle source. Large upload validation yields to the event loop.
- Pasting the main address into a new secondary-IP row leaves it editable. Saved status metadata is retained; the main address is not duplicated in secondary displays.
- Late settings responses no longer roll back the master UI state; refresh timestamps do not discard an unsaved interval.
- Pinned transitive basic-ftp 6.2.6 addressing GHSA-5pm8-86m8-9m6r and GHSA-r4jh-29pc-gfqr. No new permissions or public endpoints.
- Updated RU/EN/FA/ZH guidance. Database migration 205. Cohort: Installer 1.2.169, Node 1.1.32, Core 1.1.19 / Xray 26.11.9.
