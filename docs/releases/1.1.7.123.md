# 1.1.7.123

При запуске и переносе ноды панель различает доступный управляющий API и ещё не готовый Xray. Отсутствующий `xrayInfo` запускает согласование конфигурации с сохранением задержек повторов. Временный 503 статистики проверяется через аутентифицированный health API; первая задача после запуска панели выполняет также проверку нод. Неудачная постановка начальной задачи остаётся доступной для повтора.

Встроены WASM и схема Core 1.1.20 на официальном Xray v26.11.9. Документация Xera на RU/EN/FA/ZH описывает проверенные HTTP/2-профили Chrome 133/155, согласование Client Hints, границы статического маркера и обновление компонентов. Действующие настройки подписок, геофайлов, квот и IPv4/IPv6 сохраняются.

Комплект: Panel/Page 1.1.7.123, Node 1.1.34, Core/WASM 1.1.20, Installer 1.2.171. Обновление панели не обновляет удалённую ноду или клиентское приложение; проверяйте активное ядро и подтверждение применения конфигурации.

## English

During node startup and migration, the panel distinguishes an available control API from Xray readiness. Missing `xrayInfo` triggers configuration reconciliation while retaining retry backoff. Temporary statistics HTTP 503 is checked through authenticated health; the first scheduler task after panel startup also performs health discovery. Failed initial queue insertion remains retryable.

Includes Core 1.1.20 WASM and schema on official Xray v26.11.9. RU/EN/FA/ZH Xera documentation covers verified Chrome 133/155 HTTP/2 profiles, aligned Client Hints, static marker limitations and component updates. Existing subscriptions, geofiles, quotas and IPv4/IPv6 settings are preserved.

Bundle: Panel/Page 1.1.7.123, Node 1.1.34, Core/WASM 1.1.20, Installer 1.2.171. A panel update does not update remote nodes or client applications; verify the active core and configuration acknowledgement.
