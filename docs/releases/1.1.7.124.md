# 1.1.7.124

Редактор и схема пересобраны из Core 1.1.21 на официальном Xray v26.11.9. Справка Xera на RU/EN/FA/ZH описывает Browser Dialer, ECH, IPv4/IPv6 и выбор режима в зависимости от доступности TCP, UDP и CDN. Исторические измерения не выдаются за гарантию доступности в конкретной сети.

Обновлены зависимости интерфейса, API и страницы подписки, включая i18next 27/react-i18next 18. Сохраняются четыре языка, RTL, даты, интерполяция и перевод кодов ошибок; пустой перевод использует английский fallback. Метрики используют поддерживаемый Prometheus client и общий registry endpoint.

Runtime — Node.js 26.13.1 LTS. Комплект: Panel/Page 1.1.7.124, Node 1.1.35, Core/WASM 1.1.21, Installer 1.2.172. Новых миграций БД нет; настройки геофайлов, подписок, автоматической разморозки, квот и IPv4/IPv6 сохраняются. Удалённые ноды и клиентские приложения обновляются отдельно.

## English

Rebuilds the editor and schema from Core 1.1.21 on official Xray v26.11.9. RU/EN/FA/ZH Xera documentation covers Browser Dialer, ECH, IPv4/IPv6 and selecting modes according to TCP, UDP and CDN reachability. Historical measurements are not presented as availability guarantees for a particular network.

Updates interface, API and subscription page dependencies, including i18next 27/react-i18next 18. Preserves four languages, RTL, dates, interpolation and translated error codes; empty translations use English fallback. Metrics use the maintained Prometheus client and the endpoint's shared registry.

Runtime: Node.js 26.13.1 LTS. Bundle: Panel/Page 1.1.7.124, Node 1.1.35, Core/WASM 1.1.21 and Installer 1.2.172. No new database migrations; geofile, subscription, automatic thaw, quota and IPv4/IPv6 settings are preserved. Remote nodes and client applications require separate updates.
