# 1.1.7.125

Добавлены правила примечаний за заданное число дней до окончания ACTIVE-подписки. Поддерживаются внутренние и внешние сквады, упорядоченные сообщения и HTTPS-действия, один маркер {HOSTS} с уже разрешёнными пользователю подключениями или выдача только примечаний. Более близкое к окончанию правило имеет приоритет; после продления окно пересчитывается. Сохранены проверки HWID, квот и прав, полное переопределение внешнего сквада и совместимость обновлений от старых API-клиентов. Редактор получил общую форму, предпросмотр, явное наследование и сохранение черновика при ошибке.

Исправлено ложное online при отказе Core и ошибках SOCKS-прокси. Явный Core=false не сохраняет подключённое состояние; устаревшие uptime, online users и live-метрики очищаются. Кэшированный успех не подтверждает восстановление отключённой ноды. Ошибка соединения или аутентификации прокси не подменяется успешным health-check; правила повторной конфигурации и backoff сохраняются.

Статусы disabled и connecting имеют приоритет над connected, обновлением и оплатой во всех представлениях нод и фильтрах. Нулевой uptime сам по себе не делает активную ноду offline; realtime-счётчики исключают неактивные кэшированные показатели.

Редактор и схема пересобраны из Core 1.1.21 на официальном Xray v26.11.9. Справка Xera на RU/EN/FA/ZH описывает Browser Dialer, ECH, IPv4/IPv6 и выбор режима в зависимости от доступности TCP, UDP и CDN. Исторические измерения не выдаются за гарантию доступности в конкретной сети.

Обновлены зависимости интерфейса, API и страницы подписки, включая i18next 27/react-i18next 18. Сохраняются четыре языка, RTL, даты, интерполяция и перевод кодов ошибок; пустой перевод использует английский fallback. Метрики используют поддерживаемый Prometheus client и общий registry endpoint.

Runtime — Node.js 26.13.1 LTS. Комплект: Panel/Page 1.1.7.125, Node 1.1.36, Core/WASM 1.1.21, Installer 1.2.173. Добавлена миграция триггера ревизии кэша внешних сквадов: старый запрос не возвращает устаревшие примечания после сохранения, очистки или включения наследования. Настройки геофайлов, подписок, автоматической разморозки, квот и IPv4/IPv6 сохраняются. Удалённые ноды и клиентские приложения обновляются отдельно.

## English

Adds remarks rules for a configurable number of days before an ACTIVE subscription expires. Supports internal and external squad targeting, ordered messages and HTTPS actions, one {HOSTS} marker containing already authorized connections, or remarks-only delivery. The closest expiry threshold wins, and renewal recalculates eligibility. Preserves HWID, quota and authorization checks, complete external-squad overrides and updates from older API clients. The editor shares one form with previews, explicit inheritance and draft retention after failed saves.

Fixes false online states when Core fails or the SOCKS proxy is unavailable. Explicit Core=false cannot retain connected status; stale uptime, online-user and live-metric samples are cleared. A cached success cannot confirm recovery of a disconnected node. Proxy connection or authentication failure is not converted into a successful health check; configuration retry and backoff rules remain in place.

Disabled and connecting states take priority over connected, upgrade and billing flags across node views and filters. Zero uptime alone does not make an active node offline; realtime counters exclude inactive cached samples.

Rebuilds the editor and schema from Core 1.1.21 on official Xray v26.11.9. RU/EN/FA/ZH Xera documentation covers Browser Dialer, ECH, IPv4/IPv6 and selecting modes according to TCP, UDP and CDN reachability. Historical measurements are not presented as availability guarantees for a particular network.

Updates interface, API and subscription page dependencies, including i18next 27/react-i18next 18. Preserves four languages, RTL, dates, interpolation and translated error codes; empty translations use English fallback. Metrics use the maintained Prometheus client and the endpoint's shared registry.

Runtime: Node.js 26.13.1 LTS. Bundle: Panel/Page 1.1.7.125, Node 1.1.36, Core/WASM 1.1.21 and Installer 1.2.173. Adds a database trigger migration for external-squad cache revisions: an older request cannot restore stale remarks after saving, clearing rules or enabling inheritance. Geofile, subscription, automatic thaw, quota and IPv4/IPv6 settings are preserved. Remote nodes and client applications require separate updates.
