# Panel / Page 1.1.7.127

Комплект: Panel и страница подписки **1.1.7.127**, Node **1.1.38**, Installer **1.2.175**, Core и редактор **1.1.22** на основе Xray **26.11.9**. Обновление панели не заменяет удалённые ноды.

- Возвращён компактный список адресов с фиолетовой меткой «Панельный». Сохранённые адреса выключаются переключателем; порядок задаётся стрелками.
- Node 1.1.38 сообщает назначенные IPv4 и IPv6. Новые IP добавляются раз в 30 минут при доступной ноде; ручной перескан также удаляет исчезнувшие автоматически найденные адреса. Ручные записи, порядок и выключенные состояния сохраняются. Ошибка или неполный список не очищают адреса.
- Ошибка SOCKS5 показывается на первом шаге мастера у нужного поля. Исправлены повторная отправка формы, применение результата поиска и обработка устаревших ответов.
- Недоступная соседняя нода больше не должна останавливать независимые хосты. Если полную общую политику подтвердить нельзя, зависимые хосты закрываются до её восстановления; панель показывает отдельное предупреждение. Полное открытие требует подтверждения правил, квоты и ограничения сохраняются.
- Периоды ожидания выбора маршрута не считаются новым сетевым отказом. Подтверждённые неудачные проверки учитываются между фоновыми заданиями; порядок результатов защищён при записи статуса и метрик, поэтому старая ошибка не отменяет более новый успех.
- Стандартные GeoIP/GeoSite сохраняют обычные категории вместе с пользовательскими наборами. Поддерживаемые Happ/INCY могут восстановить полные стандартные файлы при включённых системе геофайлов и JSON. Явные Routing и geodata остаются приоритетными.
- «Обновить» проверяет источник сразу. Сравнение идёт по SHA-256: неизменный файл не перезаписывается, изменение при прежнем размере учитывается. Расписание задаётся отдельно для каждого источника в панели; для новых стандартных наборов по умолчанию установлено 48 часов.
- Исправлена доставка контрольных сумм DAT через страницу подписки, включая запросы `.sha256` после параметров URL. Сворачивание стандартных геофайлов сохраняет черновики и учитывает уменьшение движения.
- Руководство и сообщения ошибок согласованы на RU/EN/FA/ZH. Новый поиск IP требует права API `nodes:rescan-ips`.

Установщик применяет новую миграцию, сохраняющую результаты поиска адресов. Перед обновлением сохраните резервную копию. Работающий Core, настройки транспорта и ресурсы редактора остаются версии 1.1.22; обновлять их ради этого выпуска не требуется.

## English

This release restores compact node addresses with a purple panel-management badge and enable/disable switches. Node 1.1.38 supports IPv4/IPv6 discovery, persistent 30-minute append-only checks and explicit rescans that remove only disappeared automatically discovered addresses. Manual entries, ordering and disabled states remain intact.

The create wizard reports invalid SOCKS settings at their field. Route retry periods no longer manufacture failures or leave confirmed failed nodes falsely online. Standard and custom geofiles coexist without losing ordinary categories such as CATEGORY-RU; explicit Routing/geodata remain authoritative. Manual refresh bypasses the automatic deadline, compares exact SHA-256 values and preserves unchanged files. DAT checksum delivery through the subscription page handles path and query forms. The standards panel preserves drafts and reduced motion.

Panel/Page must be updated together. Remote nodes update separately; the new rescan requires Node 1.1.38 and the explicit API permission `nodes:rescan-ips`. Core/editor 1.1.22 / Xray 26.11.9 remain unchanged.
