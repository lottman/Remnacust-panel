# Panel / Page 1.1.7.129

Комплект: Panel и страница подписки **1.1.7.129**, Installer **1.2.177**, Node **1.1.38**, Core и редактор **1.1.22** на основе Xray **26.11.9**. Обновление панели не заменяет удалённые ноды или выбранное ядро.

- Полные автоматические проверки IP раз в 30 минут теперь удаляют исчезнувшие ранее подтверждённые адреса, включая ранее ручные. Ручные NAT и резервные IP, которых нода никогда не сообщала, а также имена хостов сохраняются. Поиск работает при доступном API даже без запущенного Core; неполный, неудачный или устаревший ответ не очищает список.
- Удалённый подтверждённый IP не возвращается через прежнее поле адреса в списках SSH и геопроверки. При удалении последнего доступного адреса нет скрытого подключения к старому адресу.
- Хосты показывают DANGLING и красное выделение при отсутствующем или изменившем принадлежность inbound. Выбор, сохранение и клонирование используют согласованные проверки привязки. Адрес в карточке сохраняет положение при разном наборе иконок.
- Прокрутка оглавления документации и главного бокового меню не прокручивает статью при достижении края. Размер оглавления учитывает доступную высоту, мобильный экран и уменьшение движения.
- Исправлен ответ API при отсутствии сведений о системе ноды в кэше. Отсутствующие метрики не подменяются здоровым состоянием. При выходе из сессии очищаются сохранённые запросы, чтобы предыдущие списки не переходили в следующую сессию.
- Руководство согласовано на RU/EN/FA/ZH. Права доступа, проверки сертификатов, ограничения и проверка формата API сохранены.

Перед обновлением сохраните резервную копию. Схема БД и API не расширяются этим выпуском. Core и ресурсы редактора не меняются; новые двоичные файлы ядра ради этого выпуска не нужны.

## English

This cohort contains Panel/Page **1.1.7.129**, Installer **1.2.177**, Node **1.1.38** and Core/editor **1.1.22** based on Xray **26.11.9**. Updating the panel does not replace remote nodes or the selected Core.

- Complete automatic 30-minute IP checks retire disappeared addresses previously confirmed by the node, including manually entered addresses later confirmed. Manual NAT/backup IPs never reported by the node and hostnames are retained. Discovery works through an available API while Core is down; failed, incomplete or stale responses retain the list.
- Retired addresses cannot return through the legacy address field in SSH or geo checks. Removing the last confirmed route does not enable a hidden fallback.
- Hosts show a red DANGLING state for missing inbounds or inbounds belonging to another profile. Selection, saving and cloning use consistent binding checks. Card addresses remain aligned when action icons differ.
- Documentation contents and the main sidebar contain scroll input at their edges. The contents pane follows the available viewport height, including mobile and reduced-motion settings.
- A missing cached system-info object now produces a valid API response without fabricated healthy telemetry. Logout clears query state so previous lists do not carry into the next session.
- RU/EN/FA/ZH operator help is updated. Permissions, certificate checks, limits and API response validation remain enforced.

Back up before updating. This release adds no database schema or API fields. Core and editor resources remain unchanged; new Core binaries are not required.
