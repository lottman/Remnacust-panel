# Panel / Page 1.1.7.130 — локальное исправление

Пересканирование IP сохраняет положение окна, фокус и содержимое формы при успехе и ошибке. Во время запроса остаётся видимый индикатор; повторное нажатие не запускает второй запрос. Сообщение об ошибке находится рядом со списком адресов. Поля выбора интеграций и тегов выровнены по вертикали.

Node 1.1.38 и Core/редактор 1.1.22 не изменяются. Опубликованный комплект Installer 1.2.177 содержит Panel/Page 1.1.7.129; эта сборка устанавливается отдельно.

## English

IP rescanning preserves modal position, focus and form content on success and failure. A visible indicator remains during the request; repeated clicks do not start another request. Errors appear beside the address list. Integration and tag fields are vertically centered.

Node 1.1.38 and Core/editor 1.1.22 are unchanged. Published Installer 1.2.177 contains Panel/Page 1.1.7.129; this build is installed separately.

## فارسی

جستجوی دوبارهٔ IP در حالت موفقیت و خطا، موقعیت پنجره، تمرکز و محتوای فرم را حفظ می‌کند. نشانگر هنگام درخواست دیده می‌شود و کلیک دوباره درخواست دیگری ایجاد نمی‌کند. خطا کنار فهرست نشانی‌ها نمایش داده می‌شود. متن فیلدهای انتخاب یکپارچه‌سازی و برچسب به‌صورت عمودی وسط‌چین است.

Node 1.1.38 و Core/ویرایشگر 1.1.22 تغییر نکرده‌اند. بستهٔ منتشرشدهٔ Installer 1.2.177 شامل Panel/Page 1.1.7.129 است؛ این ساخت جداگانه نصب می‌شود.

## 简体中文

重新扫描 IP 在成功和失败时均保留弹窗位置、焦点和表单内容。请求期间保留可见指示器，重复点击不会启动第二个请求。错误显示在地址列表旁。集成和标签选择字段的文字保持垂直居中。

Node 1.1.38 和 Core/编辑器 1.1.22 未变。已发布的 Installer 1.2.177 包含 Panel/Page 1.1.7.129；此构建单独安装。
