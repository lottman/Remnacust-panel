# Panel / Page 1.1.7.131 — частное исправление

Удаление ноды подтверждается после удаления записи из базы. Если применяется конфигурация, панель возвращает A272: дождитесь завершения и повторите удаление. Удаление не останавливает и не удаляет контейнер на сервере. Сообщение и инструкция доступны на русском, английском, персидском и китайском языках.

Node 1.1.38, Core/редактор 1.1.22 и схема БД не меняются. Холодный запуск и смешанный парк проверяются отдельно от удаления. Этот выпуск не входит в опубликованный Installer 1.2.177 с Panel/Page 1.1.7.129.

## English

Node deletion is acknowledged after the database record is removed. During configuration delivery, A272 asks the operator to wait and retry. Deletion neither stops nor removes the server container. The message and instructions are available in Russian, English, Persian and Chinese.

Node 1.1.38, Core/editor 1.1.22 and the database schema are unchanged. Cold startup and mixed fleets are tested separately from deletion. This build is not included in published Installer 1.2.177 with Panel/Page 1.1.7.129.

## فارسی

Node 1.1.38، Core/ویرایشگر 1.1.22 و ساختار پایگاه داده تغییر نکرده‌اند. راه‌اندازی سرد و مجموعهٔ مختلط جداگانه بررسی می‌شوند. این ساخت در Installer 1.2.177 منتشرشده با Panel/Page 1.1.7.129 قرار ندارد.
