# Panel / Page 1.1.7.132 — частное исправление

Панель повторно проверяет временную неготовность ноды перед сбросом метрик. Свежая статистика сохраняет подключение и очищает старую причину «Core не готов». Подтверждённая недоступность продолжает определяться; предупреждения о политике доступа сохраняются. В журнале состояния записывается номер успешной попытки.

Исправление совместимо с Node 1.1.38. Node, Core/редактор 1.1.22 и схема БД не меняются. Опубликованный Installer 1.2.177 содержит Panel/Page 1.1.7.129; эта сборка устанавливается отдельно.

## English

The panel rechecks temporary node readiness failures before clearing metrics. Fresh statistics preserve connectivity and clear the old Core-not-ready reason. Confirmed unavailability remains detectable, and access-policy warnings are preserved. Health history records the successful attempt number.

Compatible with Node 1.1.38. Node, Core/editor 1.1.22 and the database schema are unchanged. Published Installer 1.2.177 contains Panel/Page 1.1.7.129; this build is installed separately.

## فارسی

پنل پیش از پاک کردن معیارها، آماده نبودن موقت نود را دوباره بررسی می‌کند. آمار تازه اتصال را حفظ و پیام قدیمی آماده نبودن Core را پاک می‌کند. عدم دسترسی تأییدشده و هشدارهای سیاست دسترسی همچنان مشخص می‌مانند. شمارهٔ تلاش موفق در تاریخچهٔ وضعیت ثبت می‌شود.

با Node 1.1.38 سازگار است. Node، Core/ویرایشگر 1.1.22 و ساختار پایگاه داده تغییر نکرده‌اند. Installer 1.2.177 منتشرشده شامل Panel/Page 1.1.7.129 است؛ این ساخت جداگانه نصب می‌شود.

## 简体中文

面板会在清除指标前复查节点的暂时未就绪状态。新统计保留连接状态并清除旧的 Core 未就绪原因。确认不可用的情况仍可检测，访问策略警告保持不变。状态历史记录成功检查的尝试次数。

兼容 Node 1.1.38。Node、Core/编辑器 1.1.22 和数据库结构未变。已发布的 Installer 1.2.177 包含 Panel/Page 1.1.7.129；此构建单独安装。
