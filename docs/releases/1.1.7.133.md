# Panel / Page 1.1.7.133 — частное исправление

В списке адресов ноды восстановлено меню статуса IPv4/IPv6 с сохранением выбранной метки. Изменение статуса не меняет переключатели управления или приоритет адресов. Имена хостов сохраняют информационный значок роли управления. Убраны блок ручной диагностики подключения и вкладка «Порты и профили» вместе с переходом из карточки конфигурации. Автоматическое наблюдение и журнал остаются доступны.

Обновлены RU/EN/FA/ZH и встроенная справка. Node 1.1.38, Core/редактор 1.1.22 и схема БД не меняются. Комплект 1.1.7.133 устанавливается отдельно от опубликованного Installer 1.2.177.

## English

Restored the IPv4/IPv6 status menu in the node address list. Saving a label does not change management switches or address priority. Hostnames retain their informational management-role icon. Removed the manual connection diagnostics block and the Ports and profiles tab with its navigation button. Automatic monitoring and health history remain available.

RU/EN/FA/ZH and the embedded guide are updated. Node 1.1.38, Core/editor 1.1.22 and the database schema are unchanged. This private Panel/Page build is installed separately from published Installer 1.2.177.
