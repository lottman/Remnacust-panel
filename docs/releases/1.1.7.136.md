# Panel / Page 1.1.7.136

Удаление записи ноды больше не конкурирует с бесконечными фоновыми попытками доставки. Панель блокирует новые доставки, безопасно дожидается текущей операции и удаляет запись без подключения к серверу ноды. Предельное ожидание блокировки — 130 секунд. Успех возвращается только после удаления в БД. Защита текущей операции и чужой блокировки сохранена.

Уведомления об ошибках используют текущий язык интерфейса, включая ошибки, возникшие до смены языка. Описание A272 исправлено на RU/EN/FA/ZH: занята операция панели, а не обязательно работающая нода.

Node 1.1.39, Core/редактор 1.1.22 и схема БД не изменяются. Рабочие ноды не переключаются.
