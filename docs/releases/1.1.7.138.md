# Panel / Subscription Page 1.1.7.138

Первое обнаружение, фоновое сканирование и ручной повторный поиск присваивают новым IPv4 и IPv6 роль «Неизвестный». При повторном обнаружении сохранённого адреса его роль остаётся прежней. Обновление не изменяет существующие записи и не требует миграции.

## English

Initial discovery, scheduled checks and manual rescans assign the Unknown role to new IPv4 and IPv6 addresses. Existing roles are preserved when the same address is rediscovered. This release has no data migration.
