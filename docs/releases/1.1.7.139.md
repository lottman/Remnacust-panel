# Panel / Subscription Page 1.1.7.139

- В редакторе IP-адресов ноды снова можно удалить адрес и сохранить изменения. Чтобы убрать последний активный адрес управления, сначала включите другой.
- Панель запоминает ручное удаление. Сканирование его не возвращает. Вручную добавленный обратно адрес снова участвует в обычной синхронизации.
- Полная синхронизация удаляет исчезнувшие обнаруженные IP по прежним правилам. Она добавляет новые адреса с ролью «Неизвестный» и сохраняет роли существующих.
- Миграция добавляет пустую таблицу исключений для адресов. Данные существующих нод не переписываются.

## English

Manual address removal is applied when the node is saved and persists across scans. Adding the address manually restores normal discovery. Full scans retain the prior retirement behavior and label only newly discovered addresses Unknown. The migration adds an empty per-node exclusion table.
