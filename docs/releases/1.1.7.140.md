# Panel / Subscription Page 1.1.7.140

- Кнопка «Обновить» на странице нод обновляет список, метрики из него, плагины, интеграции и профили. Если запрос уже выполняется, панель дожидается его завершения. Успешное обновление подтверждается уведомлением.
- В список нод больше не загружается ключ установки. Он запрашивается при открытии формы ноды.
- Зависимость Prisma `effect` обновлена до 3.22.5. [GHSA-7589-6fvf-x4pw](https://github.com/Effect-TS/effect/security/advisories/GHSA-7589-6fvf-x4pw).

## English

The Nodes refresh button synchronizes the list, its telemetry, plugins, integrations and profiles. The panel reuses requests already underway and confirms successful refreshes. Setup credentials are fetched when a node form opens. The release updates Prisma’s Effect dependency to 3.22.5.
