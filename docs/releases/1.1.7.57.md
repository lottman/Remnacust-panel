# 1.1.7.57

Панель и страница подписки **1.1.7.57**, установщик **1.2.91**. Нода **1.1.19**, Core/WASM **1.1.11** сохраняются.

- Новый статус **«Заморожен»** останавливает срок подписки и доступ. Остаток времени сохраняется точно до активации; повторная заморозка не меняет остаток. Продление, массовые операции, экспорт/импорт, фильтры и страница подписки учитывают этот статус. При активации проверяются истечение срока и исчерпанный трафик.
- Автовыбор связывает хосты-получатели с конкретным балансером. Источники пула и получатели разделены; проверка префиксов учитывает реальные генерируемые теги. Доменная маршрутизация и ограничения доступа сохраняются. Отдельная функция постоянного HAProxy-входа удалена; состав серверов обновляется вместе с подпиской.
- Шаблоны можно дублировать вместе с настройками, черновиком, тегами и ссылками на геофайлы. Назначения получателей очищаются в копии. Для копирования через API нужны права чтения источника и создания шаблона.
- Разделы автовыбора и геофайлов упорядочены, дополнительные настройки свёрнуты, сохранение остаётся доступным. Некорректный код сохраняется черновиком; активный конфиг не заменяется. Ошибки указывают конкретный пул и поле.
- Подсказка сниппета копирует только полный JSON. Подсказка графика трафика следует за курсором. Журнал обновления автоматически прокручивается, сохраняя возможность читать предыдущие записи. Убран повторный переключатель полного доступа API-токена.
- Пояснение `leastLoad.tolerance` различает исходный JSON и значение внутри Xray: `2` остаётся в JSON, но ядро использует `1`; `0` отключает проверку доли неудачных проб. Для резервных копий объяснён формат PostgreSQL custom и преобразование в SQL.
- Установка ноды принимает существующий пустой каталог и выдаёт конкретную причину отказа. Установщик повторяет обязательные вопросы и приводит карту путей к Compose, `.env`, сертификатам и журналам. Перенос существующей страницы подписки выполняется по выбору с проверкой и откатом.
- HTTP-01 при ограничении доступа ноды IP-адресом панели использует временное правило только для TCP 80 с автоматическим истечением. Продление сертификата устанавливает те же ограниченные pre/post hooks. Внешний firewall провайдера необходимо настраивать отдельно.
- Массовое изменение пользователей больше не скрывает ошибки БД и синхронизации доступа; повторные задания ограничены и повторно проверяют устройства. Срок токена служебных инструментов и его cookie не превышает срок родительской сессии даже при смене секунды во время подписи.
- Обновлены руководство, API-описания и локализации EN/RU/FA/ZH. Отчёт с результатами и ограничениями: [аудит выпуска](../RELEASE-AUDIT-20261028.md).

## Обновление

Выпуск добавляет миграцию `20261027190000_frozen_user_lifetime`: поле `users.frozen_at`, триггер переходов и ограничение согласованности. Обновляйте через установщик с резервной копией. Для отката версии с этой миграции нужна согласованная копия БД; старый backend не поддерживает статус FROZEN.

Смена состава клиентского пула требует обновления подписки. Уже настроенные вручную внешние HAProxy-сервисы не удаляются установщиком автоматически. Проверки в изолированной среде не заменяют установку на каждом конкретном VPS и проверку всех версий сторонних приложений.
