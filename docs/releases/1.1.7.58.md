# 1.1.7.58

- Истёкшую подписку нельзя заморозить. Проверка действует в API и PostgreSQL, включая массовые изменения и импорт. Повторная заморозка сохраняет остаток срока.
- У замороженного пользователя вместо редактора даты показан сохранённый остаток синим цветом. Сохранение карточки не меняет срок. Жёлтое предупреждение у действующей подписки появляется за три дня, красное — после окончания.
- В настройках подписки добавлено управление зарегистрированными страницами на сервере панели: список, запуск, остановка, перезапуск и отдельное обновление. Эти операции доступны только администратору панели, не API-токенам.
- Установщик 1.2.93 добавляет отдельную установку и обновление страниц подписки. При установке панели можно установить страницу вместе с ней; при обновлении панели можно перенести найденную старую страницу. Обновление страницы сохраняет её конфигурацию и состояние запуска; ошибка готовности вызывает откат Compose.
- Исправлена выдача геофайлов INCY: подписанный выбор файлов находится в пути, поэтому запрос контрольной суммы, добавленный к полному URL, остаётся корректным. Ссылка INCY не меняется при очередном интервале проверки. Предыдущие ссылки поддерживаются.
- Интерфейс и руководство обновлены на RU, EN, FA и ZH.

Добавляется миграция `20261028190000_reject_expired_freeze`. Нода 1.1.19 и Core/WASM 1.1.11 не меняются. Для управления страницами нужен локальный установщик 1.2.93 и его служба управления. Отдельная страница и панель должны быть обновлены согласованно для новых ссылок геофайлов; обычные подписки и старые ссылки сохраняют совместимость.

- Исправлен переход INCY с загрузки DAT на встроенные правила: прежний профиль получает пустые URL и интервал 0. Вручную заданный заголовок маршрутизации сохраняется.
- Сохранение закреплено в длинных карточках настроек; короткие формы и уже закреплённые панели сохранены. Переключатели получили плавное перемещение бегунка с учётом RTL и reduced motion.
- В сравнении версий редактора восстановлена мини-карта кода; на узких экранах она скрывается ради ширины текста. Скачиваемый OpenAPI JSON теперь отформатирован.
- Собственные старые каталоги установки переводятся в постоянные panel/node; данные и тома сохраняются, неиспользуемые старые папки убираются в backups/retired-layout. Первая статья руководства объясняет .env, Compose и применение изменений.
