# 1.1.7.65

- Исправлен порядок маршрутов автовыбора и геофайлов: общий маршрут `udp,tcp` больше не делает добавленные правила недостижимыми. Для sing-box учитываются оба порядка TCP/UDP в массиве.
- Одинаковые IP-префиксы и доменные условия из выбранных категорий DAT включаются один раз. Разные типы условий, действия DIRECT/REJECT и приоритеты правил сохраняются. Это уменьшает конфигурацию без удаления уникальных правил и без принудительного включения загрузки клиенту.
- Highcharts обновлён до 13.1.1, i18next-http-backend — до 4.0.4 с опубликованными исправлениями безопасности.
- Справка по размеру встроенных правил обновлена на русском, английском, персидском и китайском. Интерфейс автовыбора и геофайлов проверен при ширине 360 и 1440 px, включая RTL.

## Совместимость и установка

Комплект: установщик **1.2.100**, панель и страница подписки **1.1.7.65**. Исходные коммиты ноды **1.1.19** и Core/WASM **1.1.11** сохранены. Новых миграций БД нет.

Установщик распознаёт нашу страницу подписки на занятом порту, включая восстановление потерянной регистрации. Подтверждённо принадлежащая установке страница обновляется на месте с сохранением `.env` и токена. Сервис не определяется только по имени процесса или номеру порта. Неизвестный владелец порта сохраняется; интерактивно можно выбрать другой порт. Ввод домена подтверждается с ответом `y` по умолчанию.

## Проверки и ограничения

Локально прошли 698 backend-тестов и 256 frontend-тестов, 19 проверок настоящего JWT/API, проверка параллельного импорта через PostgreSQL и переключение приоритета на двух настоящих ядрах Xray. Шесть платформенных/необязательных backend-проверок выполняются в соответствующих CI-стендах.

Для INCY iOS 2.6.2 точный допустимый размер полного JSON не найден в открытой официальной документации. Удаление повторов сокращает выдачу, но устранение конкретной ошибки на iPhone не заявляется без проверки на устройстве. Для больших наборов используйте меньше категорий или поддерживаемую удалённую загрузку с полной JSON-подпиской. Выключенный переключатель сохраняет встроенный режим.

В backend остаётся предупреждение низкого уровня для транзитивного deepmerge без опубликованной исправленной версии; путь эксплуатации через проверенные функции не подтверждён. Проверки не включали VPN-туннель и не изменяли рабочую панель.

Кандидат 1.1.7.64 / 1.2.99 не публиковался как стабильный: проверка Docker обнаружила повреждение UTF-8 в сохранённой справке OpenAPI. Справка восстановлена и сверяется со свежесгенерированным backend-контрактом; эта проверка добавлена и в CI исходников. Теги кандидата сохранены.
