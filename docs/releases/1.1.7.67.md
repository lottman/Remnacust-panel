# 1.1.7.67

Исправлена выдача больших встроенных геоправил для INCY iOS. Причиной ошибки `The configuration is too large` были не только исходные данные: повторное форматирование JSON с четырьмя пробелами увеличивало реальную конфигурацию с 475 021 до 1 000 909 байт. Простого удаления отступов на сервере было недостаточно.

Длинные списки IP и доменных условий без запятых теперь выдаются в строковой форме `StringList`, которую поддерживает Xray. Сохранены все элементы, их порядок, ограничения и действия. Массивы с регулярными выражениями, содержащими запятые, не преобразуются. Настройка «Загружать клиенту» не меняется: выключенная загрузка продолжает означать встроенные правила.

Преобразование выполняется только для INCY и только после сбора ссылок на геофайлы. Оно действует также при ручном заголовке `routing` и резервном переходе к встроенным правилам. Другие приложения сохраняют прежний формат выдачи. Перед ответом проверяется размер каждого конфига после форматирования с четырьмя пробелами: консервативный бюджет панели — 900 000 байт с запасом для клиентских изменений. Если конфигурация не помещается даже после преобразования, сервер отклоняет выдачу; приватный журнал содержит причину и предложение уменьшить встроенные правила или включить поддерживаемую загрузку DAT. Правила не обрезаются.

На реальной подписке конфигурация после форматирования уменьшилась с 1 000 909 до 427 209 байт. Отдельно проверяются автоматический выбор, ручная маршрутизация, отказ сборки DAT, сохранность всех элементов и выражения с запятыми. Документация обновлена на русском, английском, персидском и китайском.

Основание совместимости: [StringList в Xray](https://github.com/XTLS/Xray-core/blob/main/infra/conf/common.go), [правила маршрутизации Xray](https://github.com/XTLS/Xray-core/blob/main/infra/conf/router.go), [полные конфигурации INCY](https://docs.incy.cc/en/full-xray-config/). Официальная документация INCY не указывает точный предел iOS 2.6.2; бюджет панели не выдаётся за ограничение всех версий приложения.

После установки панели и отдельно установленной страницы подписки обновите подписку в INCY: уже сохранённый JSON на устройстве сам не заменяется. Проверка установленным ядром INCY выполнялась в режиме `-test`, без запуска туннеля. Проверка на физическом iPhone не выполнялась.
