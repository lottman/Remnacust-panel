# 1.1.7.70

- Независимый аудит закрыл дополнительный сбой при большом числе хостов: лимит сложности обхода JSON теперь считается по одному профилю; ошибка построения заголовка может переключить выдачу на DAT. Проверен случай 13 профилей по 16 000 regexp-условий без лишней загрузки файлов.
- Исправлен обрыв больших геофайлов на странице подписки: лимит JSON 16 MiB больше не обрезает поток DAT. DAT ограничен отдельно 64 MiB; проверка реальным HTTP-потоком 23 MiB подтвердила полный размер и SHA-256. Обновлять нужно также отдельно установленную страницу подписки.
- Исправлены старые значения в карточке хоста после bulk update. Все изменения хостов сбрасывают общий и индивидуальный кэш, отменяют устаревшие запросы; редактор ждёт свежие данные и сохраняет только изменённые поля. Сохранение хостов выполняется до ответа API, отдельно от фоновой синхронизации правил нод.
- Одновременные запросы DAT и контрольной суммы используют одну сборку одного набора; прежнее дублирование могло приводить к временной недоступности при холодном кэше. Ограничения разных сборок сохранены.
- Профили геофайлов получают название подписки из `profile-title`, включая переопределения сквада. Если названия нет — используется домен подписки. Короткий стабильный суффикс различает одинаковые названия.
- Убрана ручная настройка «Загружать клиенту». Сначала все выбранные наборы встраиваются в правила. Если профиль превышает бюджет клиента или лимит разворачивания правил, совместимым Happ/INCY выдаются объединённые DAT. Категории, DIRECT/REJECT, балансеры и порядок маршрутизации сохраняются.
- Размер INCY считается по каждому итоговому профилю после компактного представления и форматирования. Хосты не суммируются для сравнения с бюджетом 900 000 байт; отдельный транспортный предел ответа 16 MiB сохраняется. Это консервативный бюджет панели, не заявленный разработчиком точный предел INCY.
- Большие DAT проверяются без разворачивания всех строк. Из HTTP-заголовка при необходимости убирается только дублирующая проекция категорий: полные правила остаются в JSON. Отказ загрузки или конфликт с собственным routing возвращает ошибку, правила не отбрасываются.
- Небольшие наборы sing-box/Mihomo/Stash встраиваются; большие загружаются в подходящем формате. Бинарный SRS и собственные наборы старого Clash остаются удалёнными для совместимости. Интервалы клиента и серверного обновления сохранены и действуют независимо.
- Интерфейс, предварительный просмотр устройства и документация синхронизированы на четырёх языках. Старое поле `downloadToClient` читается для совместимости, но не управляет доставкой и удаляется при редактировании привязки в GUI.

Обновите панель и отдельно установленную страницу подписки, затем саму подписку в приложении. Маленькая конфигурация не требует анимации скачивания. Старый профиль Remnacust может остаться отдельной записью в приложении: сервер не может переименовать чужую локальную запись. Физический iPhone в проверке недоступен; VPN не запускался.

Нода 1.1.19 и Core 1.1.11 не меняются. Новых миграций БД нет.
