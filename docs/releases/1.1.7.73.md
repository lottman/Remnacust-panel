# 1.1.7.73

- Исправлена автоматическая доставка геофайлов в Happ/INCY: расчёт учитывает разворачивание Xray StringList и форматирование клиентом. Небольшой HTTP-ответ больше не скрывает превышение бюджета полной конфигурации. Проверяется каждый профиль, хосты не суммируются; большие управляемые наборы выдаются как DAT без потери правил.
- Ссылки на геофайлы и .sha256 используют HTTPS-домен запроса подписки, в том числе CDN. Страница передаёт свой адрес панели с проверкой действующего ограниченного API-токена. Сервер подключения к панели не меняется, произвольные forwarded-заголовки игнорируются. CDN/прокси должен сохранять исходный Host.
- Предупреждение о JSON-подписке показывается только при подтверждённо выключенной настройке. Убраны плашки ожидания/успеха и повторяющиеся объяснения доставки у каждого файла. Общая подсказка корректно подставляет название настройки.
- Документация и подсказки синхронизированы на ru/en/fa/zh.

Обновите **панель и страницу подписки** до 1.1.7.73 (комплект 1.2.109), затем обновите подписку в приложении. Старые сохранённые конфигурации автоматически не заменяются. Новых миграций БД нет; нода 1.1.19 и Core 1.1.11 прежние. Проверки и ограничения: [отчёт](../audits/geofile-delivery-security-2026-11-01.md). Рабочие серверы обновляются отдельно оператором.
