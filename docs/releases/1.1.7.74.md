# 1.1.7.74

- Управление основными и CDN-доменами подписок в настройках страниц: стабильные UUID, API-права, значение по умолчанию и привязка к пользователю.
- Зарегистрированный CDN сохраняется в ссылках DAT. Неизвестный Host не подставляется в клиентскую выдачу; адрес серверного подключения страницы к панели не должен использоваться как публичный домен подписки.
- Страница фильтрует заголовки с адресом приватного upstream и отказывается отдавать конфигурацию, содержащую этот адрес.
- Истёкшую подписку можно заморозить с нулевым остатком. Ручная дата скрыта при заморозке; продление сохраняется, одновременная заморозка не перезаписывает более новую дату.
- Обновлены .env.sample, операторская документация, API и четыре локализации.

Добавлены две миграции БД. Обновите панель и страницу подписки вместе, предварительно сохранив резервную копию. Нода 1.1.19 и Core/WASM 1.1.11 не меняются. Для публичных подписок используйте отдельный домен страницы; DNS, сертификат и проксирование должны быть настроены до его назначения.
