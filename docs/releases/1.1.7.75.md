# 1.1.7.75

- Перед обновлением проверяется реально применённая автономная политика всех обслуживающих нод, экземпляр ядра/журнала и ревизия. Незавершённый переход квот, recovery, недоступность или изменение состава откладывают остановку панели.
- Координатор повторно проверяет живое ядро перед начальным барьером. Глобальная фаза ACTIVE больше не выдаётся за готовность каждой ноды.
- Установщик 1.2.111 повторяет проверку перед остановкой приложений. Для старой панели без команды проверки использует временный контейнер из нового проверенного образа, сохраняя работающую установку.
- Защитный патч deepmerge препятствует подмене прототипа при объединении схем. Патч проверяется по SHA256 при установке; npm audit сохраняет предупреждение по исходной версии пакета.
- Обновлены документация и EN/RU/FA/ZH. При отказе проверки экран обслуживания сразу освобождается.

Новых миграций в этом выпуске нет. Нода 1.1.19 и Core 1.1.11 не меняются. Автономная нода сохраняет последние подтверждённые права, сроки и конечные резервы: отключение панели не делает квоты безлимитными. Новые блокировки и продления доходят после восстановления связи. Ручной docker compose down обходит проверку. Явный `--allow-disruption` предназначен только для осознанного обслуживания с возможным перерывом.

Изолированный VLESS/XHTTP-тест подтвердил старые и новые соединения через 95 секунд без панели и корректный отказ при истечении срока/резерва. Проверены настоящие PostgreSQL и mTLS/RSA, Linux bootstrap, установщик, TypeScript и сборка. Реальный CDN оператора, физические iOS-клиенты и обновление production в эту проверку не входили.
