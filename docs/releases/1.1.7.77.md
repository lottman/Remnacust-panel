# 1.1.7.77

- Основной домен подписки синхронизируется с SUB_PUBLIC_DOMAIN в .env в обе стороны через локальную службу установщика 1.2.113. Сохраняются остальные настройки и секреты; перезапуск для новых ссылок не требуется.
- Исправлен импорт HTTPS URL и адресов с путём из .env. API проверяет файл при запуске, открытии списка и каждые 30 секунд. Старое окружение контейнера не отменяет изменения на сервере.
- При конфликте файлов, ошибке записи или недоступной службе нет ложного подтверждения. Копии изменений сохраняются отдельно в backups. CDN остаются в реестре и не заменяют переменную основного адреса.
- Вкладка страниц подписки расположена после основных настроек и получила иконку. Блок доменов доступен при ошибке управления локальными страницами. Ошибки загрузки и сохранения разделены.
- Заголовки страниц и карточек используют единое оформление и акцент Theme Settings в светлых и тёмных темах. Дополнены иконки оставшихся заголовков. Цвета состояния и опасных действий сохранены.
- Документация и сообщения обновлены на RU/EN/FA/ZH. Новых миграций БД нет; нода 1.1.19 и Core 1.1.11 прежние.

Проверены PostgreSQL, приватный Unix-сокет, конфликты ревизий, сохранение секретов и откат, а также интерфейс на мобильной ширине и смена тем. DNS и сертификаты доменов настраиваются отдельно. Рабочие серверы этим выпуском автоматически не обновляются.
