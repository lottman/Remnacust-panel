# 1.1.7.78

- Исправлена ошибка 500 при открытии доменов подписки: модуль доменов теперь подключает CQRS-зависимости проверки браузерной сессии и API-токенов. Существующий домен из SUB_PUBLIC_DOMAIN снова доступен в списке.
- Добавлен HTTP-тест настоящего модуля, контроллера, JWT, CQRS и проверок прав. До исправления он воспроизводит ошибку 500. Проверяются отзыв сессии, истечение и отзыв токена, отказ без прав и доступ с правом чтения.
- Проверка готовых Docker-образов дополнена реальными запросами списка, чтения, создания, изменения и удаления CDN-домена, а также проверкой ограниченного токена.
- Документация обновлена на RU/EN/FA/ZH. Миграций и изменений формата API нет; существующие переводы сообщений сохранены. Нода 1.1.19 и Core 1.1.11 не меняются.
