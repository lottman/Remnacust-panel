# 1.1.7.79

- Новые CDN-ссылки автоматически содержат путь с ID зарегистрированного домена. Подписка, геофайлы, контрольные суммы и персональные ссылки устройств сохраняют CDN-адрес, даже если VK обращается к источнику с Host основного сайта.
- В списке доменов добавлено окно «Настроить CDN»: источник, Host/SNI и преобразование обычной ссылки или ключа в готовый CDN-адрес. Преобразование выполняется в браузере без отправки ключа на сервер. API возвращает вычисляемый publicBaseUrl, а ссылки пользователя и шаблонов формируются автоматически.
- Существующие ссылки и основной домен сохранены. Для старой ссылки через CDN с подменой Host требуется одна замена URL в приложении. Отдельный DNS-поддомен источника и правила переписывания пути не нужны.
- Проверяются ключ, статус, заморозка, срок и HWID как прежде. ID домена не даёт доступа к подписке. Публичный resolver выдаёт только публичный адрес зарегистрированного CDN, без родительского источника, данных пользователей и адреса панели. Неизвестные, вложенные и некорректные пути отклоняются; действительность токена страницы проверяется при передаче контекста конфигурации.
- Обновлены RU/EN/FA/ZH и документация. Новых миграций и переменных окружения нет. Нода 1.1.19 и Core 1.1.11 прежние.
