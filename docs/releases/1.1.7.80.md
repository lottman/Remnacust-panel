# 1.1.7.80

- Один раз задайте заголовок запроса `X-Remnacust-CDN: <UUID CDN-домена>` в VK или Яндексе. Обычные ссылки клиентов продолжают работать при подмене Host источника; подписка, геофайлы, контрольные суммы, HTML/QR и персональные ссылки сохраняют CDN-адрес.
- Окно настройки показывает готовые имя и значение заголовка, источник HTTPS и Host/SNI с кнопками копирования. Преобразование старых ссылок свёрнуто в запасной вариант для CDN без заголовков; ссылки 1.1.7.79 сохраняются.
- UUID выбирает только зарегистрированный CDN. Некорректные, неизвестные и конфликтующие селекторы отклоняются. Заголовок не является авторизацией; ключ, статус, заморозка, срок, HWID и действующий токен страницы проверяются как прежде.
- Исправлены инструкция и переводы RU/EN/FA/ZH. Новых миграций БД и переменных окружения нет. Обновите панель и страницу подписки вместе. Нода 1.1.19 и Core 1.1.11 прежние.
