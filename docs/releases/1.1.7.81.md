# 1.1.7.81

- Для каждого CDN показывается индивидуальное нейтральное имя заголовка вместо общего названия проекта. Имя и случайный UUID-значение стабильны при обновлениях и перезапусках. В VK/Яндексе замените только имя новым из окна «Настроить CDN», сохранив значение.
- Существующее общее имя и ссылки с ID в пути продолжают работать. Неизвестные ID, несоответствие имени значению, дублированные и конфликтующие селекторы отклоняются. Заголовки потребляются на публичной странице, не пересылаются панели и не возвращаются клиенту в ответе.
- API доменов возвращает вычисляемое поле `requestHeaderName`; для основного домена оно равно `null`. Новых секретов, переменных окружения и миграций нет. Имя — публичный селектор, а не пароль и не средство скрыть остальные признаки трафика.
- Обновлены документация и RU/EN/FA/ZH. Проверены стабильность имён, два CDN, старые настройки, JSON, DAT, SHA-256, фильтрация заголовков и отзыв токена страницы. Нода 1.1.19 и Core 1.1.11 прежние.
