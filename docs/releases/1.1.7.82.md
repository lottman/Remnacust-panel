# 1.1.7.82

- Для каждого CDN используется индивидуальное нейтральное имя заголовка, сформированное с закрытым ключом установки. Имя нельзя вычислить только из публичного UUID. Оно сохраняется после обычных обновлений и перезапусков; отдельная смена APP_SECRET требует заново скопировать имя в CDN. Закрытый ключ не покидает сервер.
- В VK/Яндексе замените только старое общее имя новым из окна «Настроить CDN», сохранив UUID-значение. Ссылки пользователей и прежняя настройка продолжают работать.
- Проверяются совпадение имени с доменом, неизвестные ID, дубли и конфликты. Заголовок потребляется публичной страницей, не пересылается панели как авторизация и не возвращается клиенту в ответе. Проверки подписки и действительности токена страницы сохранены.
- В API доменов добавлено `requestHeaderName`, для основного домена — `null`. Документация и RU/EN/FA/ZH обновлены. Новых переменных .env и миграций нет. Нода 1.1.19 и Core 1.1.11 прежние. Случайное имя не скрывает остальные признаки трафика.
