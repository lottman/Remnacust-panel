# 1.1.7.83

- Исправлены правила GeoIP в Xray JSON: итоговый профиль использует `IPOnDemand`, поэтому DIRECT, REJECT и балансеры по IP работают для доменных адресов перед общим правилом TCP/UDP. Это действует для встроенных диапазонов и удалённых DAT. Исходный шаблон и приоритет предыдущих ручных правил сохраняются; только GeoSite и другие форматы клиентов не меняют DNS-стратегию. Обновите подписку в приложении для получения нового профиля.
- В карточке пользователя доступны обычная ссылка и до трёх CDN с отдельными копированием и QR-кодами. Все адреса используют одну подписку. API позволяет получить все ссылки, только обычную, только CDN или конкретный домен; права на эти методы выбираются отдельно. Каталог доменов поддерживает фильтры типа и основного домена. Четвёртый CDN нельзя добавить или перенести даже при параллельных запросах. Существующие лишние записи автоматически не удаляются.
- Core и валидатор обновлены до Remnacust 1.1.12 на опубликованном стабильном Xray v26.10.31. В ядре по умолчанию выключен MPTCP, обновлены загрузчик геоданных, XHTTP, DNS, QUIC sniffer и CLI. Исходящий XDRIVE сохраняет совместимый формат старых узлов. Проверенные сборки ядра включены в каталог после проверки публичных бинарников; образ Node 1.1.20 содержит это же ядро.
- Повторно проверены официальные выпуски Remnawave: backend/frontend 3.4.7, node 3.4.3 и subscription-page 8.0.1 уже включены. Неопубликованные коммиты и отозванные выпуски не добавлены.
- Справочник API, документация и переводы RU/EN/FA/ZH обновлены. Новых миграций БД и переменных .env нет. Обновляйте панель и страницу подписки вместе. Установка новой панели не обновляет удалённые ноды автоматически; для нового ядра обновите ноду или её Core через штатное управление.

Источники: [Xray v26.10.31](https://github.com/XTLS/Xray-core/releases/tag/v26.10.31), [Remnawave backend](https://github.com/remnawave/backend/releases/tag/3.4.7), [Remnawave node](https://github.com/remnawave/node/releases/tag/3.4.3).
