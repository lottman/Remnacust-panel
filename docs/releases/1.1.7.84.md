# 1.1.7.84

- Исправлена повторная переустановка профиля геофайлов Happ/INCY при неизменившейся подписке: LastUpdated больше не равен времени каждого запроса. Изменения файлов, режима доставки, адреса или интервала продолжают обновлять профиль. Параллельные API-процессы используют одну атомарную метку для устройства; перезапуск панели её не сбрасывает.
- Сохранены исправление GeoIP и опубликованный Xray v26.10.31 из 1.1.7.83. Документация синхронизирована на RU/EN/FA/ZH. Новых переменных .env и миграций нет. Обновите подписку в клиенте один раз после установки.

Проверки: реальные запросы к основному домену и CDN выявили изменение LastUpdated при одинаковом JSON. Регрессии проверяют неизменность метки, переходы DAT/правила, смену файлов и конкурентные запросы в настоящем Redis. Успешная проверка конфигурации Xray не подтверждает запуск системного туннеля iOS; туннели при проверке не включались.
