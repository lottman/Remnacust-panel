# 1.1.7.87

- Исправлено обновление профиля геофайлов после удаления GeoIP или GeoSite: ссылка и все списки правил удалённого вида передаются пустыми. Один оставшийся файл не наследует старые правила второго; DAT одного вида пересобирается только из актуальных источников.
- Проверен переход с сохранённого профиля предыдущей версии: имя сохраняется, новая ревизия применяется один раз, повторный одинаковый запрос не запускает новый импорт. Обновление источника меняет активное содержимое DAT; расписание и последний рабочий файл переживают перезапуск приложения.
- Ревизия учитывает SHA-256 активных файлов. Изменение содержимого обновляет профиль даже при прежнем адресе DAT и в пределах текущего интервала; неизменившийся файл не получает новую ревизию от каждого запроса.
- QR-коды подписки и отдельных ключей получили явные размеры, контрастный фон, поле с исходной ссылкой и обработку некорректных данных. Резервная ссылка в карточке пользователя также имеет QR.
- Новые CDN-ссылки используют обычный поддомен без автоматически добавленного `/cdn/<ID>`. Старые ссылки продолжают работать. Согласованы версии служебного определения домена для старых и новых страниц подписки.
- Публичная страница сохраняет домен входа для ссылки, QR и импорта. Персональные ссылки устройств сохраняют свою идентичность и окончание пути.
- Обновлены README, документация и локализация RU/EN/FA/中文. Миграция `20261102193000_inactive_subscription_hosts` обновляет разрешения хостов-исключений для FROZEN/LIMITED. Новых переменных панели `.env` нет.

- Добавлены настраиваемые примечания FROZEN и позиция заморозки в порядке примечаний, включая внешние сквады. Разрешённые хосты для неактивного доступа работают при заморозке и исчерпании общей квоты; обычные хосты и HWID-блокировки не обходятся.
- Проверены реальные правила Browser/Base64, явные JSON/Mihomo/Sing-box пути, запреты и настройка JSON на основном/CDN-домене.
- Node 1.1.21 применяет совместимые изменения без рестарта; обычная смена порта/транспорта проходит проверку и автоматический перезапуск Xray с восстановлением предыдущего checkpoint при неудаче. Краткий разрыв возможен; строгий requireLiveApply сохранён.

Согласованный комплект — установщик 1.2.125. Обновите панель и отдельно установленную страницу подписки, затем обновите подписку в приложении. Публикация версии не меняет уже работающие серверы. Системный VPN при проверках не включался; локальные тесты не заменяют проверку конкретной версии приложения на физическом iPhone.
