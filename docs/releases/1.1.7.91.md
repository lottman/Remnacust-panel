# 1.1.7.91

- «Скачать журнал» в обновлении панели скачивает настоящий технический вывод. Операции страниц подписки получили такую же кнопку. Доступ ограничен администратором и текущей задачей; секреты удаляются из скачиваемой копии. Для большого журнала отдаётся последний 1 MiB, исходный файл остаётся приватным на сервере.
- Исправлена ошибка Raw Subscription при скрытых ключах: пустой UUID допустим только в этом ответе и только при отказе доступа устройству. Общие контракты пользователей по-прежнему требуют UUID.
- Колонка действий HWID-инспектора получила фиксированную ширину. Предупреждение редактора учитывается при расчёте его высоты и остаётся над кнопками сохранения.
- Добавление уже связанного балансера не создаёт дубликат. Незавершённый балансер с именем пула остаётся в той же карточке и дополняется на месте. Ручные правила и параметры сохраняются.
- Созданный или скопированный шаблон сразу попадает в список из ответа сервера. Кнопки перетаскивания остаются по центру карточек при наведении и уменьшении анимации.
- Меню опций хоста предпочитает открываться вверх; его высота ограничивается доступным местом, а результаты поиска прокручиваются внутри меню.
- Адрес HTTP-проверки ограниченного хоста выбирается из разрешений без расширения доступа. Автоматическая настройка Happ требует настоящего Provider ID; INCY настраивает URL в приложении либо через свой Premium API. Это не изменение обработки пинга нодой.
- Обновлены встроенное руководство и локализация RU/EN/FA/中文.

Панель и страница подписки 1.1.7.91; комплект установщика 1.2.129; Node 1.1.21; Core 1.1.12. Новых миграций и переменных `.env` нет.
