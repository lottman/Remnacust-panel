# 1.1.7.92

- Разные холодные сборки геофайлов ожидают ограниченную очередь: две активные задачи и до 32 принятых задач на операцию. Одинаковые запросы разделяют одну сборку; ограничения кэша DAT сохранены.
- Страница подписки ожидает панель до 30 секунд вместо 10, сохраняя отмену при отключении клиента и прежние ограничения размера. Метаданные и другие API-запросы сохраняют отдельный короткий таймаут.
- При выдаче геофайлов через страницу подписки сохраняется ETag. Поддерживается проверка If-None-Match и ответ 304 без повторного тела файла; приватные подписки не кешируются.
- Один хост можно назначить нескольким автовыборам. Каждый выдаётся отдельным профилем; источники, ключи, лимиты трафика и скорости остаются общими. Прямые назначения приоритетнее тегов; явный шаблон хоста сохраняет приоритет.
- Для завершённого обновления журнал подготавливается заранее и скачивается обычной ссылкой внутри модального окна. Проверены повтор после ошибки запроса и мобильная ширина 390 px. Запросы отменяются при смене задачи и закрытии компонента.
- Когда системные пакеты требуют SSH-терминала, панель показывает отдельную причину остановки. Настройки пакетов не выбираются скрытно; подробный журнал сохраняется.
- Обновлены руководство и локализация RU/EN/FA/中文.

Панель и страница подписки 1.1.7.92; комплект установщика 1.2.130; Node 1.1.21; Core 1.1.12. Обновляйте панель и страницу подписки вместе. Новых миграций и переменных `.env` нет.
