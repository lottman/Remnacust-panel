# 1.1.7.93

- Теги хостов располагаются рядом с названием и провайдером. Длинные названия, несколько тегов и двухколоночный список не раздвигают карточку; мобильная версия сохраняет доступ к полному тексту.
- Подключение через автовыбор использует квоту, скорость и множитель хоста-получателя. Лимиты участников пула применяются при прямом подключении к ним. Общий лимит аккаунта сохраняется.
- Несколько автовыборов одного получателя делят его квоту. Ключи одного устройства делят предел скорости и долю очереди между всеми серверами пула.
- Проверяются текущие права на получателя и источник, статус пользователя, HWID и родительский ключ. Отзыв одного источника не открывает другой. Поздняя статистика удалённого источника сохраняет владельца квоты.
- Обновлены документация и локализация RU/EN/FA/中文.

Комплект: панель/страница 1.1.7.93, Node 1.1.22, Core 1.1.13, установщик 1.2.131. Миграция `20261104010000_autoselect_quota_ownership` добавляет внутренние маршруты и ключи; новые переменные `.env` не нужны. Обновите ноды и подписки клиентов: прежние ключи и исторический расход сохраняют прежний учёт. Для обычных нативных групп без хоста-получателя поведение не меняется.
