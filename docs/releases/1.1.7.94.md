# 1.1.7.94

- Проверка выданных ключей выполняется наборами SQL вместо вложенных проверок для каждой строки. Сохраняются проверки статуса, срока, сквадов, HWID, родительского ключа и прав на источник/получателя автовыбора.
- Подготовка подписки не читает выданные ключи; сборка конфигурации ограничивает выборку ключей нужным профилем. Проверки доступности пользователей в лимитах и координаторе квот также выполняются наборами.
- Одновременные синхронизации одной ноды объединяются с повторной сборкой для изменений, поступивших во время отправки. Другие процессы повторяют попытку вне SQL-транзакции, не занимая соединение базы в очереди той же advisory-блокировки.
- Страницы подписки с выключенным показом ключей не создают ссылки, которые затем выбрасываются. Оптимизация использует существующие заголовки страницы и сохраняет API старых страниц. Обычные API-запросы и страницы с показом ключей сохраняют прежнюю выдачу. Срок ожидания сведений в обновлённой странице увеличен с 10 до 30 секунд.
- Штатная Remnawave-нода может получать базовую конфигурацию без расширения host-policy-v2. Ошибки сети не считаются признаком старой ноды. Сохранённые квоты, скорость, правила сайтов и специальный доступ при неактивной подписке требуют совместимых Node/Core и не обходятся.
- Обновлено руководство RU/EN/FA/中文. Новых переменных окружения и миграций нет.

Комплект: панель/страница 1.1.7.94, Node 1.1.22, Core 1.1.13, установщик 1.2.133. Обновление панели не обновляет ядро удалённой ноды.
