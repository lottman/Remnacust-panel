# 1.1.7.95

- Повторная синхронизация ноды ставится в конец ограниченной очереди. Непрерывные изменения больше не удерживают три рабочих места за первыми нодами; каждый запрос ожидает свою подтверждённую обработку, а не все будущие изменения.
- Проверка поддержки ноды выполняется до массовой сборки конфигурации. Полностью отклонённая группа не запускает чтение всех пользователей. Рабочий Xray не останавливается при ошибке проверки или БД.
- Массовая подготовка пользователей использует SQL-наборы вместо построчных вызовов функций доступа. Сохраняются сквады, срок, статус и правила входов. Паузы лимитов читаются одним запросом на ноду.
- Подтверждённые штатные Remnawave-ноды получают базовую конфигурацию без требования кастомного Core. Новые лимиты хостов, ограничения сайтов и неактивные хосты-исключения отключаются на их входах. Кастомные ноды, использующие тот же inbound, получают совместимые обычные ключи; отдельные совместимые inbound сохраняют расширения.
- Старое кастомное ядро без поддержки учёта получателя автовыбора использует обычные ключи и ограничения серверов пула. Для отдельного учёта получателя нужны обновление Node/Core и обновление подписки клиента. Режим совместимости показывается в карточке ноды на четырёх языках.
- Сетевой сбой, неизвестная версия или версия, сохранённая для другого адреса, не считаются доказательством совместимости. Существующие финансовые резервы и блокировки не удаляются ради понижения версии.
- API прежних страниц подписки сохранён. Обновлены руководство и локализация RU/EN/FA/中文. Новых миграций и переменных `.env` нет.

Комплект: панель/страница 1.1.7.95, Node 1.1.22, Core 1.1.13, установщик 1.2.134. Обновление панели не заменяет ядра удалённых нод.
