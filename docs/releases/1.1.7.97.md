# 1.1.7.97

- «Поддержать проект» в документации сразу открывает страницу с адресами. Старая ссылка на статью перенаправляется без лишнего шага в истории.
- Заголовки разделов левого оглавления стали контрастнее и закрепляются при его прокрутке. Выбранная тема выделяется цветом текущей темы; поддерживаются мобильная ширина и RTL.
- Загрузки геофайлов используют отдельный пул соединений. Одновременные медленные DAT-загрузки не занимают соединения для страницы подписки и конфигурации приложения. При перегрузке файлов возвращается временный ответ с возможностью повторить запрос; отмена закрывает поток.
- Эпохи квот записываются пакетами до 500 строк в общей транзакции ревизии. Накопленный расход фиксируется пакетами до восьми квитанций; подтверждения Redis удаляются после фиксации PostgreSQL. Повторы не списывают трафик дважды. Координатор сохраняет курсор по владельцу и продлевает аренду между областями с проверкой поколения.
- До холодного запуска проверяется совместимость ноды и её соседей с общими входящими подключениями. Политика и конфигурация используют один снимок. Недоступный узел не задерживает независимые исправные ноды. Неизвестная совместимость сохраняет прежний конфиг и назначает повтор, а не отключает ограничения.
- Срок доступа и снимки устройств сравниваются в UTC независимо от часового пояса PostgreSQL. Миграция `20261104190000_utc_access_expiry` обновляет функции доступа, не меняя сохранённые даты, остаток заморозки и квоты. Старая операция удаления не затрагивает устройство, заново зарегистрированное или заблокированное после получения списка.
- Из журналов ошибок убраны ключи подписки в путях; отладка Marzban больше не выводит секреты подписи и содержимое токенов. Контракты ответов API сохранены.
- Исправлено обрезание названий тегов хостов. Руководства RU/EN/FA/中文 описывают ограничения пакетов, UTC и совместимость. Новых переменных `.env` нет.

Комплект: панель/страница 1.1.7.97, Node 1.1.22, Core 1.1.13, установщик 1.2.136. Обновление панели не обновляет удалённые ноды. Для передачи клиенту исправлений выдачи геофайлов обновите и панель, и страницу подписки.
