# 1.1.7.98

Изменения относительно Panel и страницы подписки 1.1.7.97. Согласованный комплект: Installer **1.2.137**, Panel/Page **1.1.7.98**, Node **1.1.23**, Core/WASM **1.1.14** на официальной основе Xray v26.10.31. Обновление установленного сервера выполняется отдельно для каждого компонента.

- Исправлены зависания SPA-маршрутов sirv и чтение PEM-файлов вне разрешённого каталога панели. Патчи зависимостей проверяются по SHA-256; ограничения размера и специальных файлов сохранены.
- Ограничены параллельные batch-запросы подписок. Disconnect прекращает неначатые lookups; уже начатая работа удерживает лимит до завершения, включая ошибки. Свежие проверки прав и квот сохраняются.
- HTML страницы подписки после ошибки subscription-info отменяет и дожидается ненужного запроса page rules. Сохраняются исходные 404/503, локализованные ответы и параллельный успешный путь; ускорение успешных запросов не заявляется. Ошибка шаблона или SQL не выдаётся за пустую успешную подписку.
- Защищены ответы после мутаций API: создание/изменение не предоставляет автоматически право чтения связанных данных. Ограниченные токены не получают секреты ноды и дополнительные поля без требуемых read-scopes.
- Уточнены метрики dashboard и диагностика БД. Кеш общих диагностических снимков не заменяет авторизацию, не даёт прав на подписки и не управляет квотами. Проверки backend SQL и миграций выполнены на PostgreSQL 14–18; перенос существующей базы требует проверки резервной копии.
- Восстановление черновиков редакторов и история согласованы с загрузкой новой сборки интерфейса. Повтор запроса после ошибки соединения не должен повторять пользовательскую мутацию. Перед обслуживанием сохраняйте изменения в редакторе.
- Автовыбор по времени ответа использует проверки HTTP/HTTPS через выбранный outbound. Для полной конфигурации сохраняются правила доступа, состав пула и настройки клиента; Xera HTTP и браузерный редактор получили согласованные поля и проверки схемы.
- Исправлены устаревшие stop/start задания ноды, порядок применения и подтверждения состояния. Желаемое отключение сохраняется при ошибке остановки; offline-удаление не требует ложного подтверждения остановки.
- Core 1.1.14 восстанавливает действующие гранты после compaction истёкших записей без возврата истёкшего кредита. Выполнены тесты **24 виртуальных часов** с перезапусками, expiry и исчерпанием; это не реальный суточный сетевой прогон и не обещание нового периода без заранее выданного гранта. Сохранены anti-replay, tombstones и watermark.
- Обновлены руководства RU/EN/FA/ZH и README на русском/английском: ресурсы, порты, постоянные каталоги, API-токены, JSON-геофайлы, DNS/CDN, копии и диагностика. Поддержка Debian 12/13 относится к новому установщику 1.2.137, а не к прежнему 1.2.136.

Обновляйте отдельно размещённую страницу вместе с панелью. Панель не обновляет удалённые Node/Core автоматически. Перед миграциями сохраняйте БД, исходный `.env`, `APP_SECRET` и постоянные тома.
