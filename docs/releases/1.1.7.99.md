# 1.1.7.99

Изменения относительно Panel/Page 1.1.7.98. Согласованный комплект: Installer **1.2.138**, Panel/Page **1.1.7.99**, Node **1.1.24**, Core/WASM **1.1.15** на основе Xray v26.10.31. Обновление установленного сервера выполняется отдельно для каждого компонента.

- Управляющий канал панели использует основной адрес и явно заданные резервные IP с ролями `MANAGEMENT`/`RESERVE`. Проверки API ограничены по времени, числу попыток и параллелизму; порт и настроенный SOCKS5 сохраняются. Скрытого перехода на direct и автоматического поиска внешних адресов нет. Администратор должен указывать адреса одной ноды: общие TLS/JWT не доказывают уникальный UUID и не отличают другую ноду с тем же доверием.
- В существующей диагностике показаны последний подтверждённый маршрут, proxy/direct, время проверки и безопасные причины неудачных попыток. Устаревший результат, ошибка запроса, новая проверка и смена UUID не сохраняют прежний зелёный маршрут. Локальная занятость проверок показывается как предупреждение, а не как подтверждённая неисправность ноды.
- Валидация SOCKS5 учитывает диапазон порта, bracketed IPv6 и приватные Docker hostname с `_`. Схема, путь и встроенные реквизиты не принимаются как адрес ноды. Редактор Proxy URL скрыт по умолчанию, но сохраняет показ и изменение значения. API-токены, включая wildcard, получают `proxyUrl: null`; администраторская сессия сохраняет настройку.
- Имена процессов панели в PM2 и системной диагностике — `rc-api`, `rc-scheduler`, `rc-processor`.
- В Installer 1.2.138 проверка выпуска не запускает APT. Фоновое обновление из панели откладывает обслуживание ОС до отдельного SSH-сеанса с записью в прогрессе и приватном журнале; само отложенное обслуживание не блокирует обновление компонентов. Интерактивный CLI сохраняет настоящие вопросы dpkg/debconf; `--yes` не выбирает настройки пакетов, автоматической перезагрузки нет. Ошибки резервной копии, миграций и обновления компонентов не выдаются за успех.
- Обновлены руководства RU/EN/FA/ZH: управляющий API отделён от VPN-трафика. SOCKS5 username/password по [RFC 1929](https://www.rfc-editor.org/rfc/rfc1929.html#section-3) передаются прокси открытым текстом; используйте доверенный прокси в приватной сети или через защищённый туннель. mTLS шифрует канал Node API, но не отдельный SOCKS5 handshake.

Набор из **194 миграций БД** сохранён. Прежние проверки 24 виртуальных часов не являются реальным суточным сетевым прогоном и не обещают выдачу новых квот без панели. До обновления сохраните БД, исходный `.env`, `APP_SECRET` и постоянные тома. [Совместимость](../COMPATIBILITY.md) · [База данных](../DATABASE-COMPATIBILITY.md) · [Резервные копии](../BACKUPS.md).
