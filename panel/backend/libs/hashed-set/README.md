# @remnawave/hashed-set

Локальные исходники пакета **0.0.4** для множества строк с инкрементальным 64-битным хешем. Пакет сохраняет имя, версию и авторство Remnawave; это не версия панели.

Экспорт `HashedSet` находится в [src/index.ts](src/index.ts). Реализация расширяет `Set<string>` и обновляет хеш при изменении состава; сравнение хешей не является криптографической проверкой целостности или заменой авторизации.

Скрипты сборки backend/frontend и типы перечислены в [package.json](package.json). Пакет собирается как часть backend; установка и проверки панели описаны в [README backend](../../README.md).

Лицензия AGPL-3.0; исходное авторство сохраняется в пакете и [NOTICE проекта](../../../../NOTICE.md).
