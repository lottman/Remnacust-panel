# Проверенные патчи зависимостей

`npm ci` запускает [apply-dependency-patches.cjs](../scripts/apply-dependency-patches.cjs) через `postinstall`. [manifest.json](manifest.json) закрепляет пути, исходный и итоговый SHA-256 и точные замены. Все файлы проверяются до записи; неизвестное содержимое останавливает установку. Повторное применение допустимо.

## Состав

- `xray-typed`: типы поддерживаемых протоколов и транспортов Remnacust.
- `sirv`: ограниченная обработка HTTP-путей в CommonJS и ESM.
- `@prisma/adapter-pg`: сохранение момента времени при чтении PostgreSQL `timestamptz` и однозначная запись UTC.

`nestjs-zod` закреплён на 5.6.0. Эта версия сама преобразует объединения типов для OpenAPI 3.0 и не зависит от `deepmerge`. Прежние патчи этих двух библиотек удалены; они больше не требуются. Это устраняет зависимость от пакета, затронутого [GHSA-gcqx-w48m-w2h4](https://github.com/advisories/GHSA-gcqx-w48m-w2h4), вместо сохранения локального исправления внутри него.

[Регрессионные проверки](../tests/dependency-patches.test.cjs) проверяют целостность патчей, повторное применение, отказ до записи при изменённом содержимом и защиту обработки входных данных. [Проверка адаптера](../tests/zod-dto-compatibility.test.cjs) использует настоящие Nest HTTP-валидацию и генерацию OpenAPI.

## Обновление

При обновлении зависимости заново проверьте необходимость каждого патча и пересоздайте manifest с фактическими хешами. Не отключайте проверку SHA-256 ради установки. После `npm ci --ignore-scripts` выполните `node scripts/apply-dependency-patches.cjs` перед использованием backend.

Docker-сборка применяет патчи до компиляции и переносит проверенные runtime-зависимости в образ. [README backend](../README.md).
